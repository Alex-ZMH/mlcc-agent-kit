## 1. 建议首先交付的基础电场闭环

建议候选操作 `electrostatics_2d`：显式参数化MLCC二维横截面、单个线性各向同性均匀介质、理想A/B等势电极、外边界自然电绝缘、明确面外深度、非零直流压差、串行一阶有限元。沿当前已能运行的DOLFINx实现抽取，不重造静电科学内核。

```text
显式专业JSON -> 公共schema和无副作用预检
-> 公共queued task/worker -> 模块科学Adapter
-> 参数化几何/语义标签 -> 网格及检查 -> 稳态静电
-> φ/E/电荷/储能/能量电容与通量诊断
-> 专业数值检查 + 未验证项声明 -> 公共结果/产物/只读读取
```

输入与输出详见INTERFACE_DRAFT.md。所有必需科学参数明确给出，保留原值与实际使用值；首版不靠LLM补材料或判科学合格。初始源例可作为**待用户确认的验证输入**，不设为任意请求的默认器件。

输出最低要求：规范化输入、方法/后端/依赖真实版本、MSH网格/语义标签、VTU节点电位及单元E/|E|、JSON积分指标、结构化检查记录、原生日志与产物hash。总Q/U/C与单位深度Q'/U'/C'分开标注；外位移通量和C_Q/C_U一致性是明确诊断，主电容为能量法。图片可作为辅助，薄器件放大图必须说明比例，尖端Emax不得解释为击穿安全。

## 2. 可选的基础多物理扩展（独立决策）

候选扩展是**稳态欧姆导电→q=J·E→稳态传热**，不是无损静电自动发热。两阶段精确共享网格、P1、同一深度；无热反馈、无迭代、无瞬态。需要额外确认：σ/k的来源与适用温度、哪些域导电、端子连接、热Dirichlet/绝热边界、功率含义、验收参考。

建议先完成来源的矩形/分层导体参考复核，再决定是否适合用户的MLCC任务。若用户要的是AC介电损耗、自热后ε/σ变化、真实电极金属导热或热应力，不能沿此profile直接承诺；需新的物理模型、输入和验证，排除在当前十天最小建议之外。

扩展若获批准：单个公共模块操作在一个task内组织A/transfer/B科学阶段，复用公共worker与产物；不搬旧CoupledOperationStore、审批数据库或另建公共DAG。源失败不启动传热；传递失败保留A结果；明确阶段失败与总结果未完成。首版最终是否包括此扩展由用户决定。

## 3. 明确非目标

- 跨尺度传参/自动多尺度编排；DFT/MD科学实现。
- 三维、有限宽边缘修正、轴对称、外空气场、任意导入CAD或完整CAD编辑器。
- 非线性/各向异性/频率或温度依赖ε、漏电/击穿、介电损耗、AC、瞬态、压电/声学、热力耦合。
- 任意多材料/缺陷/圆角产品路线；独立研究有相关代码不等于当前Agent已具备。
- 百万单元、MPI并行、网格自动自适应、全参数扫描、远程集群。
- 旧Web/CaseState/session/LLM provider、凭据、运行权限系统和整个源码包导出。
- COMSOL实现或未经验证的后端互换；只预留科学输入与后端内部的边界。
