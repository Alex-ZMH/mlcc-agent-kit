## 2. 总体执行顺序、研究门与预算

### 2.1 五个里程碑

| 里程碑 | 范围 | 必须拿到的最小真实证据 |
| --- | --- | --- |
| H0 | P0–P3 | 能力装载、Slurm 适配、工程建模、MPI、VASP 弛豫/SCF/回传 |
| H1 | P4 | 同几何 ABACUS 对照、独立弛豫、生产引擎显式切换 |
| H2 | P4 公共科学工作包＋P5–P8 | 公共物性与条件工作包、四性质链各自的方法、实际任务和可适用结果；缺项明确保留 |
| H3 | P9–P11 | 同源扩胞/映射、合格势、正常体相/界面 MD；铁电分支另验极化/场、微分介电、电致应变及界面电边界 |
| H4 | P12 | 材料/界面包、条件性器件估计、因果解释与可复现交付 |

P0 与 P1 可并行，P2 的通用函数可在研究材料未选择时用 fixture 开发。P3 真计算要求 P1 和相应工程模型就绪。P4 迁移后才开展选定案例的性质/训练标注。

P5–P8 与 P9 准备工作可以并行，但受本机资源限制，不代表允许同时占满四卡。P11 构型设计可提前，实际界面 MD 必须等对应势覆盖和 P10 基线。

当前系统验收按“能力覆盖＋真实证据＋适用边界”推进，不要求所有材料、所有指标或所有可选 P6/P8 分支都达到同一个阈值。正常工况性能预测和 comparison 是主线；conformance 只有在请求提供规格后才判定；diagnosis 可覆盖正常机理或条件性异常/劣化机制。H1 只验收 P4 的生产引擎/目标方法资格；P4 新增公共物性、条件缺陷/NEB 和界面工作包在 H2 或相应能力门验收，不成为所有后续任务的总阻塞。

### 2.2 跨链依赖以具体数据为准

- P5 极化路径可以先做；离子介电后处理等待力常数、Born 电荷和 ε∞。
- P7 谐声子需要位移力；极性非解析修正另外等待 Born/ε∞，不是所有声子作业都要等完整 P5。
- P8 的 S、σ/τ、κe/τ 不必等 κl；真实 σ/κe 需要 τ，完整 ZT 还需要 κl。
- κl 的生产路径必须指到实际任务：DFT/三阶力常数/BTE 由 P7 产生；若选择 MD 路线，必须增加 P9 势资格和 P10 热导任务的依赖。后一情形下 H2 先交已有声子/归一化输运，完整 ZT 延至 H3 相关结果完成后汇总；不能为赶 H2 在势未合格前运行 MD。
- P9 势标注可在 P4 合格方法下开始，不必等所有性质；热电结果不是扩胞的前置条件。
- P11 新表面/聚合物/分离环境可产生额外 ABACUS 标签，须回到 P9 势资格验证。
- P4 的生产引擎/目标方法资格与公共科学工作包分开：P5–P10 只依赖自身所需的 P4 电子、弹性、Born/介电、缺陷或界面数据；未被当前请求选中的条件缺陷、NEB 或界面包不构成总阻塞。
- P12 可以分批汇总，不将“部分报告已生成”标为全部科学需求已完成。

### 2.3 用户请求必须明确的科学选择

执行者一次给出有物理意义的选项，不让用户只面对技术字段。通用系统不替用户决定材料、相或设计指标：

- 模式：normal（正常工作性能计算）、comparison（设计方案比较）、conformance（设计适配评估）或 diagnosis（机制与边界分析）。normal/comparison 不要求先有阈值；conformance 没有规格时保持 not_assessed；diagnosis 说明是正常机理还是条件性异常机制。
- 化合物/组成、指定母相、结构来源、工况。无掺杂 CaZrO3/Pnma、400–580 °C（673.15–853.15 K）、1 atm 是当前已指定验证案例，不是系统默认或唯一验收案例；其他材料保持独立请求。
- 掺杂元素、A/B/阴离子位或其他占位、价态/补偿、目标和实际浓度；没有这些输入时不自动替换为 BTO 或其他材料。
- 若请求 conformance，逐指标提供名称、单位、上下限、条件、来源和 required/optional 状态；缺失阈值保留 null，不由系统猜测。
- 分布假设、独立构型数与可承受超胞规模。
- 铁电温度/电场范围；磁性是否涉及稀土 f/SOC；热电 T/载流子范围及 τ 来源。
- 晶界/界面晶向、陶瓷终止面、Ni 表面状态和必要氧化/羟基假设。
- 保留高分子或临时粘结剂两条路径中的具体化学、链长/交联/塑化条件。
- 实际介质厚度及其状态（手册中的 1–60 μm 仅为示例，不是全体系范围）；器件 N、A、工况及实验输入。

这些缺项不能静默猜成研究配置值。用户暂未决定时可继续通用实现、normal/comparison 输出和明确标记的工程 fixture；缺少 conformance 阈值只限制达标判断，不阻塞系统建设。

### 2.4 首轮资源约束

下列为拟采用的起始预算，不是本项目已经测得的运行性能：

- 研究配置默认 max_concurrent_tasks=1。CPU/CUDA 验收曾同时四卡，不等于科学批量已获固定四卡配额。
- 首条 VASP/ABACUS 工程任务从一 GPU、一 MPI rank、一物理核起步，具体内存和墙时由小基准调整。
- 四卡工程对照使用四 rank、每 rank 一 GPU；先证明正确性，不承诺小体系加速。
- 当前 --mem 是主机 RAM，不是 GPU 显存配额。27800 MiB 是节点总可调度 RAM，不为多个任务重复承诺。
- 先统计位移数/构型数/应变数/标签量，再列出每类单任务资源、总 GPU 小时和预计输出体积。
- 对近千原子 DFT、三阶力常数、全界面势训练、长聚合物或多温度长 MD，先提交独立预算；不因后台能排队就无限铺开。
- 需要系统包/服务变更时走用户可见 sudo 终端；不改驱动、重启或影响他人作业来省略调试。
- 文件保留策略先约定：大 WAVECAR/电荷/完整轨迹留服务器，结构、元数据和必要结果回本地；不自动删除原始数据。

### 3.2 最小记录

- Model：model_id、version、parent_models、source_path/version、structure_file、atom_ids、phase_requested、phase_relaxed、composition、dopants、spatial_mode、seed。
- Method：method_set、engine/version、functional、basis、pseudopotential/orbital 名称/版本/路径、电子/自旋模型、k 点、cutoff、展宽、色散、U/SOC、数值收敛与约束。
- Task：task_id、stage、model_id/version、selected_purposes、selected_scenarios、selected_required_tasks、method_set、depends_on、runner=slurm、job ID、分区/CPU/GPU/RAM/time、输入/输出目录、实际命令、原生调度状态、退出码、时间。
- Result：name、value 或 data_file、unit、conditions、method、source_task、模型版本、误差/有效范围、`scientific_status`、`design_assessment`、目标规格引用。
- `scheduler` 只记录 Slurm 原生状态和退出码；`scientific_status`（scientific validity）记录计算产物是否具备可解释的物理证据；`design_assessment` 只用于请求的规格符合性，取 `met`、`not_met`、`insufficient_evidence`、`not_assessed` 或 `not_applicable`。具体字段和条件以 [通用系统需求与验收](design-requirements.md) 为准。
- CaseValidation：`study_id`、`case_id`、`case_role`（如 `engineering_fixture`、`scientific_validation` 或用户案例）、实际科学证据、适用边界和案例结论。它与系统能力矩阵分开保存，单次结果的 `scientific_status` 不能代替案例验收。
- CapabilityRecord：`capability_id`、`case_id`、`engine/version`、`method_set`、`capability_status`（`implemented_unverified`、`verified_in_scope`、`not_implemented`、`unsupported`）及证据引用。某案例不适用只能说明该案例，不得直接把系统能力记为通过。
- 大张量、能带、频谱、轨迹用数据文件，元数据不内嵌巨量数组。
- v001 等版本与普通编号即可；不生成 checksum、内容地址或相同内容自动复用逻辑。

### 3.3 终态与科学完成必须分开

- submitted 表示拿到真实原生 job ID；不能将 SSH PID 作为 Slurm job ID。
- PENDING、RUNNING、COMPLETING、COMPLETED、FAILED、CANCELLED、TIMEOUT、OUT_OF_MEMORY 等保留原始调度信息。
- COMPLETED/0:0 只表明进程层完成；科学完成另需产物可读、电子/离子收敛及适用的物理对照。
- 缺输入、未计算、不适用、功能未实现、数值未收敛、已完成但不满足物理模型，分别记录，不全部压成零或“成功”。
- 计算失败、超时或状态不明不能直接推出材料 `design_assessment=not_met`；没有目标规格时保持 `not_assessed`。同样，正常轨迹中未发生损伤/断裂不等于设计达标，必须用目标指标和证据判定。
- 命令/查询原始错误必须保留。SSH 提交结果不明时，不自动重新提交；先查已存任务记录，无法证实则报告提交状态不明。
- 无 sacct 时在控制器保留期限内保存完整终态。查询不到旧任务不能推断成功/失败，保留事实并报告证据缺口。
- 手工诊断后调整参数并重新计算时，生成新 attempt/task 并关联旧记录；不覆盖失败日志，不伪装为自动恢复。

### 3.4 计划中的 CLI，不是现有命令

为第一版实现一套一致的最小接口，不为每个性质另造一套调度器：

~~~text
mlcc model --study <已确认的研究配置>
mlcc prepare --task <任务文件>
mlcc submit --task <任务文件>
mlcc status --task <任务文件>
mlcc cancel --task <任务文件>
mlcc collect --task <任务文件>
~~~

执行者在相应阶段实现后才能使用这些命令。若最终采用不同入口，应同步本文件与测试；不得在报告中把这些计划命令说成现在就存在。

- [ ] P7.05 按真实顺序收集位移力，计算二阶力常数。若施加声学和规则/对称化，记录原始与处理后的差异，不用它隐藏严重数值问题。
- [ ] P7.06 计算色散、DOS、软模与本征矢，检查 q 网格、超胞、位移幅度和小负频的数值来源。真实不稳定模不删、不取绝对值。
- [ ] P7.07 极性非解析修正与 P5 共享同模型 Born/ε∞，核对张量和原子顺序。缺数据时报告未做 NAC，不能默认为完整极性谱。
- [ ] P7.08 对稳定相做可适用的 Cv/自由能和必要 QHA 热膨胀；区分 Cv/Cp。强非谐/高温稳定相先定义相应方法，不直接套谐波公式。
- [ ] P7.09 对筛选后的代表性材料做三阶力/BTE κl，先统计位移数和收敛成本，不对每个随机掺杂构型无预算展开。若明确选择 MD κl，则此子项只定义交接和适用条件，实际计算必须等 P9 势资格/P10 热流与尺寸验收；不得在 P7 提前跳过这些依赖。
- [ ] P7.10 说明缺陷散射、同位素、有限晶粒和实验微结构是否包含，避免把理想晶体 κl 直接叫器件总热导。Ni 总热导还含电子项。
- [ ] P7.11 输出 force constants、位移/力文件、phonons.json、thermal-lattice.json 和参数交接。给 P5/P8 的引用指向具体模型/方法任务，不指向无版本的目录。
- [ ] P7.12 完成位移顺序、单位、可重复频率/热学基准和物理收敛测试，附全部 job ID 与失败/未提交列表。
- [ ] P7.13 对正常工况和 comparison 请求交付可用性能输出（稳定相、Cv/Cp、热膨胀、声子 DOS/群速度、κl 或明确的替代量），不能把“查找虚频”当作阶段唯一目标。温度、方向、边界、采样和误差必须随结果保存。
- [ ] P7.14 将虚频分成数值误差、真实 0 K 不稳定和有限温度稳定性问题，分别给出后续动作；虚频或无损轨迹都不能单独决定 `design_assessment`，应回到目标指标和适用方法。

完成门 G7：谐声子和 κl 分开验收；只有色散/DOS不算热导完成，有真实高温软模也不等于软件链失败。

## 12. P8：电子热电输运任务链

输入：ABACUS 稠密均匀 k 能带、自旋/电子数/晶格及输运条件；真实系数与 ZT 另有依赖。

- [ ] P8.01 明确本链是 Seebeck/电子输运，不是声子热导、自热或磁性。确定 T、化学势/载流子范围与绝缘体研究的物理目的。
- [ ] P8.02 用合格 SCF 和稠密均匀 k 采样产生能带；高对称路径 band plot 不能直接当输运积分输入。
- [ ] P8.03 固定 BoltzTraP2 版本，查该版本实际数据接口。实现 ABACUS 数据桥，不宣称存在已验证原生读取器。
- [ ] P8.04 转换晶格、k 坐标、能量零点/单位、电子数、自旋通道及必要对称信息。用解析或已知数据集和独立数值对照验证，不只检查“文件能打开”。
- [ ] P8.05 做插值与密 k/能带窗口收敛，确认简并、自旋/SOC等输入与所选后处理方法兼容，不能把不支持的数据结构硬塞进结果。
- [ ] P8.06 报告刚性带和常数散射时间近似及其限制，输出 S、σ/τ、κe/τ、PF/τ 的张量/方向、T 和 μ/浓度约定。
- [ ] P8.07 给定有来源的 τ 后才输出 σ、κe 和 PF，明确使用何种张量/方向定义。τ 未知就保留归一化结果，不填一个“典型值”冒充预测。
- [ ] P8.08 根据所选路线等待同状态/方向的具体 κl 任务：P7 的 DFT/BTE，或 P9 合格势之后 P10 的 MD 热导。后一条的完整 ZT 必须推迟到相关 H3 结果完成后；此前只验收不依赖 κl 的输运子项。张量情形先定义测量/边界方向，不把所有分量直接当标量套除法。
- [ ] P8.09 讨论带隙误差、缺陷能级/载流子与绝缘漏电代价；高电导/高热电性能不等于 MLCC 更可靠。
- [ ] P8.10 输出 transport.json、T/μ/浓度表、桥接输入/输出、单位测试、收敛证据和未确定参数。

完成门 G8：tau 归一化与实际系数分开；没有 τ/κl 时不把 ZT 标为完成。

## 13. P9：同源扩胞、力场资格与训练

输入：ABACUS 弛豫母模型、MD 目标和对应 DFT 方法集。扩胞只是几何操作，不会自动创造合格相互作用。

- [ ] P9.01 读取 P4 的明确 model/version，不从 VASP 旧文件或“最新结构”偷偷取父模型。为界面列出陶瓷和 Ni 两个或更多父模型。
- [ ] P9.02 用 ASE 整数矩阵扩胞，输出原子数/计量/晶格与 parent_atom_id＋image_index→child_atom_id。一般非对角矩阵的晶格与周期映射也须正确。
- [ ] P9.03 exact 模式原样复制掺杂/空位图样，报告人为周期相关性；randomize_after_repeat 用明确组成、补偿、种子和统计新建派生模型，不能称为逐原子相同。
- [ ] P9.04 分开 bulk、slab、晶界/异质界面构建；真空长度与实体厚度独立控制。记录取向、晶面、终止、面内变换/应变分配与边界。
- [ ] P9.05 确认 LAMMPS 二进制、版本、所需 package、CPU/GPU 路线和实际 potential 接口。程序能启动不代表 DeepMD/长程/分子拓扑包都已编译。
- [ ] P9.06 对现成势建立资格表：元素、bulk 相、缺陷、表面、界面、加载/温度、长程/电荷/自旋与聚合物拓扑。未覆盖项逐一标记，不把 bulk EAM/氧化物/有机势无标定拼接。
- [ ] P9.07 若需机器学习势，设计最小 ABACUS 标注集：平衡/应变/热扰动、目标缺陷、表面、实际界面 registry、张开/剪切与必要聚合物环境。只做平衡 AIMD 不覆盖断裂。
- [ ] P9.08 用一致 method_set 标注 E/F/应力，明确 dpdata/DeePMD 的原子类型、能量、力、应力/virial 单位与符号。先小数据转换/回读和独立构型对照，再训练。
- [ ] P9.09 按母轨迹、构型家族、加载路径/温度拆训练/验证/测试，不随机切相邻帧冒充独立测试。记录极端界面原子和断键环境误差，不只看平均力 RMSE。
- [ ] P9.10 在单卡 16 GiB 条件下建立训练资源基准，明确 batch/模型大小；不默认四卡显存池化。多模型委员会和主动学习仅在实际需要、版本相容时加入，不先搭通用 DP-GEN 平台。
- [ ] P9.11 资格验收除 E/F 外还比较晶格、应变/弹性、表面/相对 registry、分离曲线和目标温度稳定性。具体误差目标在运行前按物理量给定。
- [ ] P9.12 热传输要检查势与热流实现的多体/长程/维里支持；有 ε/P/电场任务还须额外自由度/标签，普通 E/F 势不自动给它们。
- [ ] P9.13 输出 structure.data、type_map、atom_map、parent_models、potential 文件/来源与 potential.json，写清合格范围/不支持项。新增元素、表面或聚合物后回到资格测试，不只改 type_map。
- [ ] P9.14 没有界面合格势时可验收扩胞算法、单相势和数据链，但不能把 P11 界面 MD 标为可执行。给出明确缺口与下一批标注预算。
- [ ] P9.15 以真实元素、真实目标组成/相和用户给定的范围建立资格样本，并为每类场景选正向基准（已知稳定结构、已通过的小胞或有来源的参考结果）。不以虚拟元素、任意替代元素或未标定混合势填补覆盖缺口。
- [ ] P9.16 建立能力覆盖矩阵：顺电/铁电、磁性、金属、电极/陶瓷界面、保留高分子和排胶后状态逐项记录已实现、需标注、未实现及适用边界。通用系统的通过条件是代表性场景有真实证据，不要求所有场景同时具备合格势。
- [ ] P9.17 将正常工况/设计对照的势资格与诊断/破坏加载资格分开验收；后者缺失时可继续正常性能预测，但不提交超出合格范围的破坏 MD，也不把未发生破坏解释成达标。
- [ ] P9.18 在界面势资格判定之前，消费 P4.17 已生成的、使用与 P11 相同真实元素/面内胞/约束的 ABACUS 界面 DFT 锚点（registry、间距、分离/剪切曲线及必要参考片段），并把锚点、来源任务和适用范围写入资格表。界面任务未选择或未计算时只记录执行事实；已选择但物理上不适用才记 `scientific_status=not_applicable`，无设计目标时 `design_assessment=not_assessed`。P11.03 只消费这些已生成的锚点，不反向定义 P9 的资格门，避免循环依赖。
- [ ] P9.19 按所选铁电、跨相变、局部极化或场驱动响应，明确极化/场模型路线：有效哈密顿量、局部软模/极化、诱导偶极、显式电荷/长程静电或场依赖势；把 P5 极化/介电/Born、必要 P7 力常数和 P4 DFT 标注的依赖写入模型。有效哈密顿量只有在选定实现和版本可执行时才可采用，不能把理论名称当作现成 LAMMPS 接口；只请求无场力学/热学时按对应资格执行。
- [ ] P9.20 核实实际 LAMMPS 接口、长程电荷/偶极实现、恒电势或外场边界、场能量和力的定义；对金属电极、绝缘陶瓷和高分子分别记录边界。普通 DeePMD/E/F/virial 势不自动包含极化、电场、去极化或电极屏蔽，未验证的接口只保留为未实现/待标注。
- [ ] P9.21 以独立结构/温度/应变/场和相态样本验证极化、Born/偶极、力、应力与能量一致性，并分开验收普通 E/F、极化、长程电边界和电-力耦合；极化验证失败时不能用普通 E/F 势替代，也不能把力场拟合误差当作介电误差。

完成门 G9 分为几何可用、势对具体场景合格；P10/P11 只使用已合格的场景子集。

## 14. P10：LAMMPS 体相与局部微结构 MD

输入：G9 的相应合格势/结构与明确温度/边界。LAMMPS 本阶段输出原子/粒子行为，不输出整层 FEM。

- [ ] P10.01 从小胞开始对照 LAMMPS 与 ABACUS 的相同构型 E/F/应力，核实 units、type 顺序、边界、长程和力场参数。
- [ ] P10.02 做时间步对照与短 NVE 能量漂移，确认约束、质量与势实现稳定。恒温器不能用来掩盖积分/力场错误。
- [ ] P10.03 对真正 bulk 用合适 NPT 取得温度参考晶格/密度与热膨胀；说明各向异性、取向和采样。slab/真空不套三向 bulk 压强耦合。
- [ ] P10.04 按目标做弹性/应变响应、平衡与重复种子对照，说明静态弹性和有限速率响应的区别。
- [ ] P10.05 逐一增加明确晶界、局部孔隙、表面粗糙或缺陷，保持组分/取向/边界的可比对照，不把所有缺陷同时加入后声称找到单一机制。
- [ ] P10.06 规模由数千至数万原子的小基准逐步确定。记录 atom count、GPU/CPU、步耗时、显存/RAM、采样长度和输出体积，不承诺微米厚度逐原子计算。
- [ ] P10.07 局部应力明确 virial/体积/粗粒化窗口；界面/孔隙附近原子体积不唯一，给出对定义的敏感性。位置图着色不自动成为连续应力场。
- [ ] P10.08 按 `selected_purposes` 和 `selected_scenarios` 选择松弛、迁移/滑移或缺陷演化，保存事件定义和统计。迁移和制造组织中的孔隙可属于正常状态；只有额外诊断扰动和损伤加载按相应请求启用，不以事件名称自动判劣化。纳米时间/高应变率结果不能直接解释实验寿命。
- [ ] P10.09 如做 κl，选择与势匹配的 Green–Kubo/NEMD，检验热流、体积、采样和尺寸；不把温控输入能量自动叫热导，也不把 Ni 晶格项当总热导。
- [ ] P10.10 输出真实轨迹/统计、bulk reference、误差/有效范围、Slurm 任务记录及后续界面的温度/边界参考。按科学结果筛选代表性场景，不以动画是否流畅验收。
- [ ] P10.11 仅当 `selected_required_tasks` 或承诺的能力验证选择体相 MD/相应 observable 时，完成正常工况体相基线：结构/密度、弹性响应与卸载恢复、热传输和稳定性，在多个独立样本或种子上报告均值、离散度和误差。普通请求不因未选择全套 MD observable 而阻塞；当前 CaZrO3 验证案例使用400–580 °C（673.15–853.15 K）范围内五个计划点、外压1 atm，这些值不硬编码为通用系统默认。
- [ ] P10.12 将已选择的正常性能输出与条件诊断输出分开：若选定结构/弹性/热传输 observable，正常分支报告相应结构、弹性恢复、热传输、样本数和误差；诊断分支才按请求加入迁移、孔隙、缺陷演化或损伤事件。未观测到损伤只表示该轨迹未触发事件，不自动给出 `design_assessment=met`。
- [ ] P10.13 对每个代表性场景记录尺寸/时间/速率适用边界和 `scientific_status`；设计规格缺失时交付性能预测与误差，不虚构 conformance 阈值或把计算失败写成材料 `not_met`。
- [ ] P10.14 对已通过 P9.19–P9.21 的铁电/可极化模型，按正常有限温度工况采样极化态、局部有序参数、结构相和历史依赖；区分热涨落、相变、冻结和真正的极化翻转，不以单时刻净极化为零判定非铁电。
- [ ] P10.15 在给定工作点 E0 附近使用双侧小场扰动及幅度/采样对照，或适用的平衡涨落方法，计算 D、E 及 ∂D/∂E。总极化与电子/离子来源明确，局部极化是空间划分而非额外可重复相加的贡献；不把 P/E 当作所有偏压下的介电常数。
- [ ] P10.16 在选定机械边界下计算电致应变、极化—应变或压电响应的可逆加载/卸载，记录场幅、应变张量、速率、滞后和恢复；普通力学势只能交付无场弹性，不能补写电致响应。
- [ ] P10.17 仅在 selected_required_tasks 或诊断目的要求时，计算局部畴壁/极化界面参考及其有限温度动力学；选择缺陷偶极/畴壁相互作用时先补对应 P9 模型资格，区分正常排列、钉扎和扰动。DFT 热力学电荷态不直接等于经典点电荷，缺陷浓度/分布/冻结假设须明确。保持原子/粒子 MD 尺度，不把结果写成 FEM 或微米相场求解。
- [ ] P10.18 仅在用户明确要求且 P9 极化/电边界资格覆盖时，计算场驱动翻转或 P–E 环；报告加载速率、场历史、周期数、尺寸和有限采样，不能把高场/高频 MD 结果命名为实验矫顽场或寿命。
- [ ] P10.19 输出极化态、D、E、∂D/∂E、电致应变/压电量、局部有序/畴参考、轨迹和统计交接；每个结果绑定模型、场/温度/应力/频率有效范围及 P5/P7/P9 来源任务。

完成门 G10：正常工况的积分、单位、尺寸和目标 observable 有证据，局部模型与实验/器件尺度的差距明确；铁电分支还必须有相应极化/场模型资格和已选 P(T)/D(E)/电致应变等独立证据。迁移、孔隙、损伤、局部畴和极限加载按请求验收；其中迁移/孔隙/畴本身不自动表示劣化。

## 15. P11：陶瓷/Ni 与高分子两分支界面 MD

输入：已定义表面/取向、P9 相应势资格、P10 温度/边界基线。先验收正常连接和性能，再按条件进入破坏/失效诊断；不预设高分子一定改善设计或失效。

- [ ] P11.01 仅在 `selected_required_tasks` 选择直接界面或高分子角色时，建立清晰对照矩阵：直接陶瓷/Ni；烧结后低温装配的保留高分子层；临时粘结剂所形成的排胶后接触/孔隙/残留。PI/PVB 仅是候选，未选分支不创建任务。
- [ ] P11.02 用户明确陶瓷终止、Ni 晶面/表面状态、是否氧化/羟基、取向、面内匹配和应变约束。小 coherent 界面不能代表真实松弛多晶；报告人为应变。
- [ ] P11.03 使用 P9.18 已生成的 ABACUS 代表性 registry/间距/分离锚点；片段参考保持相同面内胞、组成和相应约束。此项只完成界面模型映射、双界面计数和 MD 输入准备，不把尚未完成的锚点或资格倒推为已通过。
- [ ] P11.04 仅在选择保留高分子分支时明确化学、链长分布、交联/塑化、密度、层厚、初始取向、制备/退火与独立链构型；不默认该层可经历陶瓷共烧仍保留。
- [ ] P11.05 仅在选择临时粘结剂分支时确定研究的是反应过程还是排胶后缺陷状态。没有经验证的反应势/机理时只做后者；删除聚合物原子不是排胶/烧结模拟。
- [ ] P11.06 检查所有异种 cross interaction、键/排除项、电荷/长程、表面和拉伸环境；高分子内部合格不代表其两侧异质界面合格。
- [ ] P11.07 先完成平衡和小载荷正常响应；仅当 `selected_purposes` 包含 diagnosis 或请求明确破坏工况时，才做张开极限，并明确夹持层、活性区、温控区、面积、开口位移、横向约束、加载/卸载、速率和尺寸。
- [ ] P11.08 正常分支比较可逆剪切/滑移与卸载恢复；仅在条件破坏任务中加入 Ni 塑性、高分子松弛或断裂路径，区分两侧界面和聚合物自身路径。固定拓扑非反应模型不能可靠声称化学键断裂。
- [ ] P11.09 仅在 study 的 `selected_scenarios` 或工艺请求包含热循环/热失配时，做目标有限热循环响应；明确无应力参考温度、制备历史和机械约束。未启用该条件分支时不阻塞正常连接路径；完全弛豫晶格并不能自动定义器件残余应力。
- [ ] P11.10 界面热传输按合格 NEMD/其他明确方案计算，说明热流、温度跳变、面积、有限尺寸与稳态区间。含金属时区分晶格通道和电子贡献。
- [ ] P11.11 只有在请求启用张开/破坏或明确需要边界参数时，才分开 DFT 可逆 Wsep、MD 有限速率表观分离功、峰值强度、塑性/黏弹耗散和宏观 Gc。没有标定就不把高加载率 MD 功命名为实验 Gc。
- [ ] P11.12 仅在 selected_required_tasks 要求高分子 comparison/conformance 时，比较独立高分子构型、代表性表面/速度/尺寸，记录误差与排序是否稳定。先小对照，再扩大，不全组合无差别计算。
- [ ] P11.13 按已选正常/条件分支输出局部结构/应力定义、牵引/剪切、松弛/耗散、界面热响应、必要的失效路径、方法/有效范围和排胶后状态清单。
- [ ] P11.14 若向未来连续模型交参数，明确哪些耗散已计入，以免 Ni 塑性/高分子黏弹在 Gc 和显式本构中重复计算；不在本项目伪造 FEM/相场结果。
- [ ] P11.15 仅在 `selected_required_tasks` 选择界面/高分子响应或 comparison 时，先做小载荷正常连接：界面稳定性、界面刚度、可逆滑移/卸载恢复和热传输，固定面积、温度、边界和独立构型，输出均值、离散度及有效范围。已选择的直接陶瓷/Ni 与保留高分子层才要求可比 reference。
- [ ] P11.16 只有在 `selected_purposes` 包含 diagnosis 或明确给出破坏工况时，才增加张开极限、剪切极限、Ni 塑性、聚合物断裂/黏弹耗散等条件任务；结果标注速率/尺寸限制，不把未跑破坏任务判成设计不达标。
- [ ] P11.17 仅在选择高分子方案时，同时输出正常连接收益和电容/电气代价所需的参数，按 comparison 或 conformance 规格形成逐指标结论；没有规格时保留排序、误差和证据缺口，不宣称“改善”或“达标”。
- [ ] P11.18 若铁电陶瓷/电极界面任务被选择，定义电极屏蔽、去极化、极性终止、界面偶极、恒电势/外场和高分子边界；金属/陶瓷异质超胞不能直接套用体相 Berry-phase，电势参考和界面场须独立建立。
- [ ] P11.19 对已选择的直接陶瓷/电极、保留高分子层或排胶后接触及必要对照，在可比几何/边界下比较界面极化、屏蔽和低介电层的电压分配/电气代价；没有合格电荷/长程模型时只交接 DFT/介电参数，不虚构 MD 电场。
- [ ] P11.20 仅在 P9 电边界和势资格覆盖时计算局部电-力-热响应及可逆恢复；否则逐向交付电、力、热参数和有效范围，明确未形成耦合闭环，不把机械/热 MD 结果命名为铁电器件响应。

完成门 G11：先证明正常连接、刚度、可逆滑移/恢复和热响应的对照条件可比；若选择铁电界面，还要证明屏蔽/去极化/电边界和局部电-力-热量有相应资格，否则保留逐向参数交接状态。只有请求启用破坏/极限时，才验收相应失效路径。势支持被报告机制、速率/尺寸与工艺边界明确；不具备反应势、界面势或电场模型时保留真实未完成条件分支。

## 16. P12：材料/界面包、条件性器件估计与交付

输入：各链实际合格结果、`selected_purposes`、`selected_scenarios`、`selected_required_tasks`；只有器件估算分支额外要求相应几何/工况。缺链也能交付阶段报告，但不能宣称完整多需求预测或规格符合。

- [ ] P12.01 按 model/version 建立材料包，收录相/组成/缺陷、方法、ε/弹性/热膨胀/κ/磁性/输运及界面参数。未算/不适用分开，不由别的材料自动补值。
- [ ] P12.02 每个参数保留单位、T/E/f、方向、边界、速率/历史、统计误差、数据文件、source_task 与有效范围；方法不一致时分组，不能平均混合。
- [ ] P12.03 将手册中的 1–60 μm 作为厚度示例，不把它当作全体系硬限制；实际生坯/烧结后厚度状态、有效并联间隙 N、重叠面积 A 和电极/端头由 study 提供。缺几何就只给参数需求，不从 DFT 胞长猜器件尺寸。
- [ ] P12.04 对相同均匀并联间隙使用 C=Nε0εeff A/d 的适用近似；铁电偏压采用对应工作点 ∂D/∂E，不把零场 ε 当成全部 C(V,T,f)。
- [ ] P12.05 保留绝缘高分子时，对一个间隙先计算各层 t/ε 串联的电气厚度，再按并联间隙汇总；层内电压按电位移/边界求分配。临时粘结剂已去除的分支不能继续当作理想保留薄层。
- [ ] P12.06 仅在有真实损耗谱、电极电阻和寄生电感来源时做明确等效电路的 Z(f)、ESR/ESL/SRF 条件估计。非均匀高频寄生缺失则不伪造曲线；复电容损耗与串联电阻不重复计入。
- [ ] P12.07 不由 Eg 给额定耐压，不由声子频率给 SRF，不凭纯 BTO/CaZrO3 认证 X7R/C0G，不从纳米 MD 单次起裂给整机寿命。
- [ ] P12.08 构建机制证据链：掺杂/缺陷→局部键合/电子/软模→材料响应→局部界面松弛/失效倾向→有条件的器件影响。相关性、模型内因果和实验外推分开。
- [ ] P12.09 比较可用实验/文献时标明温度、频率、尺寸、成分/相、晶粒/孔隙与定义差异，不直接把不相同对象的数值当误差条。
- [ ] P12.10 交付报告、图表/表格、轻量原始数据、参数包、模型/方法/任务索引和逐阶段状态；失败/排除任务在统计中保留，结论只用合格证据。
- [ ] P12.11 检查所有结论能追到实际 source_task、job ID/终态和文件；对无法再从控制器查询的历史任务使用已保存快照，不编造实时状态。
- [ ] P12.12 明确退出范围：微米整层 FEM/相场、完整器件电磁、全电热力反馈和寿命/额定耐压统计属于未来独立需求；只列所需参数/实验和建议接口，不生成假求解器文件。
- [ ] P12.13 输出 H4 总结与下一最小实验/计算批次。只有实际完成当前 study 的 `selected_required_tasks`，才将该 study 的相应阶段标完成；预算耗尽不是科学完成，也不替代系统级能力验收。
- [ ] P12.14 按 `selected_purposes` 和 `selected_scenarios` 输出：normal 给出设计工况下的性能、误差和适用范围；comparison 给出同条件方案差异；conformance 才读取目标矩阵；diagnosis 单独列正常/异常机制证据，不能把诊断结果替代规格符合性。
- [ ] P12.15 为每个指标建立达标矩阵：计算/预测值或有来源的实验参照、单位、上下限、条件、裕量、`design_assessment`、来源任务/数据、未达标原因和待补证据。阈值为 `null` 或未提供时记 `not_assessed`；不把失败作业直接记 `not_met`，也不把不同来源混成单一数值。聚合规则为：任一必需且适用指标有有效证据并明确不满足则整体 `not_met`；没有已证不满足但必需指标证据不足则整体 `insufficient_evidence`；全部必需且适用指标有效满足才整体 `met`；全部指标不适用不能记 `met`。
- [ ] P12.16 明确语义边界：scheduler 状态、`scientific_status`（scientific validity）和 design_assessment 分栏保存；计算失败不等于材料不达标，未发生损伤/断裂不等于设计达标，只有相应目标和合格证据同时满足才可记 `met`。
- [ ] P12.17 分开两个验收层次：系统级总验收必须按承诺能力 × 代表性案例 × 引擎/方法版本覆盖，并附真实证据和适用边界；单个 study 只按 `selected_required_tasks` 收敛，不要求所有可选 P6/P8、所有材料或所有失效机制一次性完成。某案例对某能力 `not_applicable` 只能说明该案例不适用，不能使系统相应能力通过；列出顺电/铁电/金属/界面/高分子场景的已实现与未实现项。
- [ ] P12.18 将 P4.18–P4.27 缺陷结果及 P5/P7/P9–P11 铁电结果装入材料包：极化状态、D、E、∂D/∂E、电致应变/畴参考、缺陷形成/结合/偏聚能、化学势域、费米能级/转变能级、原始与修正能量及有效范围。P12 微分介电和条件性器件估计引用相同工况结果；无目标规格为 not_assessed，有目标而缺相关证据/资格才为 insufficient_evidence。

完成门 G12：报告范围与真实证据匹配，未完成链/条件没有被表格或漂亮曲线掩盖；normal/comparison 性能、conformance 规格判断和 diagnosis 机制结论彼此可区分。铁电/缺陷扩展必须保留其模型、修正、边界和不适用理由，不能以 CaZrO3 非极性案例或 Ni 工程 fixture 代替能力证据。单个 study 按 selected_required_tasks 收敛，系统级总验收另按承诺能力覆盖矩阵完成。没有规格时可以完成系统输出，但 conformance 保持 not_assessed。

## 17. Harness 实现与测试的最低清单

### 17.1 代码只做当前需要的事

- 单一 Python 科学工具包和薄 CLI/MCP；不再建立第二个自治研究平台。
- 确定性领域函数与明确站点适配器；不写“遇错换引擎/默认补值/猜格式”的恢复层。
- 仅支持实测选定版本；换版本先重做相应真实输出回归，不用大段兼容分支代替证据。
- Model、Method、Task、Result 记录可读；不实现内容哈希、文件摘要缓存或“自动算出失效依赖”的复杂平台。
- 任务依赖直接列真实生产数据；LLM 不能把未执行任务判成完成。
- 对外数值命令使用既定参数和明确资源；错误、权限/认证失败、超时与物理未收敛分别报告。
- 系统验收按代表性能力覆盖、真实证据和适用边界；`design_assessment` 只在 conformance 请求提供规格后判定。无阈值不阻塞实现，失败任务也不直接生成 `not_met`。

### 17.2 实现验证维度

| 层次 | 主要检查 | 不足以作为通过 |
| --- | --- | --- |
| 行为 | 保留用户选材/选相/掺杂；支持 normal/comparison/conformance/diagnosis；缺能力如实说明；区分 MD/FEM；阶段边界 | 只写出了正确文案 |
| 确定性 | 计量/浓度/补偿、原子/位移顺序、单位/应力、极化分支、能带桥/扩胞 | JSON 能 parse、文件存在 |
| 真实集成 | 平台能力发现、Slurm job/取消/回传、MPI、VASP/ABACUS/合格势 MD | fake runtime、目录扫描、CUDA smoke 代替科学任务 |

每个维度只运行当前实现有意义的测试。解析器使用去敏的真实输出；不把原始 VASP 许可证/大私有文件打包到测试数据。

三类验收另行记录：

- 能力验收：按 capability × 代表性 case × engine/method version 记录 `capability_status` 四值（`implemented_unverified`、`verified_in_scope`、`not_implemented`、`unsupported`）。
- 科学案例验收：按 `study_id`/`case_id`/`case_role` 保存结构、方法、收敛、物理证据、适用边界和 `case_validation` 结论；案例 `not_applicable` 不会使系统能力通过。
- 设计适配验收：只有存在目标规格时按指标记录 `design_assessment`；无目标为 `not_assessed`，物理不适用为 `not_applicable`，有目标但缺证据为 `insufficient_evidence`。

### 17.3 更新四项 Skill 的时机

- model-mlcc-structures：P2 函数和输入/产物稳定后更新 SOP，不把未实现 API 写成现成工具。
- run-mlcc-dft：P1/P3/P4 按真实站点接口、job 查询与生产切换更新。
- compute-mlcc-properties：P5–P8 各链方法能力实测后逐项更新，不一次宣称全支持。
- run-mlcc-md：P9–P11 势/类型/边界/observable 验收后更新。
- 每次涉及可执行能力的 Bundle 变更发布新版本，重新真实安装/启用和工具发现。已安装版本目录不原地修补。
- 不把主模型固定成某一型号；主 agent 负责架构/科学/验收，luna 只接清晰有界的实现/测试/文档任务并由主 agent 复核。
