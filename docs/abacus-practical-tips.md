# ABACUS 使用提示

用户于2026-10-23补充，并明确要求后续新计算按此设置。下列数值配置用于后续范围内的新ABACUS计算；工具能力仍按使用前核对处理。本次确认不启动计算、不修改或重跑旧任务。

1. **工具环境**：在配置了该环境的计算端使用：

   ```bash
   conda activate abacuscopilot
   ```

   用户提示可调用该环境中的工具准备ABACUS所需的PBE相关资源，或使用其支持的、计算更快的轨道。用户消息同时出现`abacuscopilot`与`abacuscopliot`两种拼写，实际可执行命令以环境内帮助为准，不猜测转换子命令。“将PBE泛函转化为ABACUS所使用的泛函”先作为用户提供的工具能力线索保留；使用前核对实际转换对象、文件格式和轨道适用范围，不能仅凭这条提示宣称泛函发生改变或轨道性能已验证。

2. **截断能**：后续新计算按用户要求，将对应截断能设为库文件描述值的约 **1.2倍（高约20%）**。记录库文件、描述中的基准值和单位、实际输入值；使用对应的截断能参数，不能混淆轨道半径等其他参数。库中缺少明确基准时记录待核对项，不凭空生成基准值。既有冻结任务和原始证据不改写。

3. **SCF步数**：用户经验是可能需要 **1000～2000步** 才能收敛，后续新任务应显式预留相应的电子迭代上限（`scf_nmax`取1000～2000范围内的明确值），并保存实际迭代数和原生收敛状态。达到阈值即可正常结束，无须强制跑满；上限较大本身不代表已收敛，也不代替离子弛豫控制。

本提示不触发既有失败任务重跑、自动加步或参数扫描。当前两窗口继续铁电/介电系统链路；新计算仍须属于既定任务范围，在v100通过Slurm执行、声明资源，实际DFT使用`time=0`。不收敛如实留档，继续独立系统开发。详见[DFT收敛规则](dft-convergence-policy-20261022.md)。
