# 当前二维 MLCC 器件有限元计算能力

更新：2026-10-22；模块fem 0.4.0。保留五个操作，并为电热、AC、EM各增加独立 *_quantities 多单位入口，八个操作通过同一Windows公共框架。模型/材料/实物适用性尚未独立签核，不能将本机运行或数值回归通过等同于产品预测有效。

## 已接入能力

| 操作 | 几何与物理 | 可返回结果 |
| --- | --- | --- |
| electrostatics_2d | 二维均匀线性无损介质、理想等势电极、自然外绝缘，明确面外深度 | 电位/E、端子Q、U、能量/通量C，总量及单位深度量 |
| electrostatics_2d_quantities | 显式长度/电势量值、单位和来源→公共唯一核心→原SI静电 | 与原静电相同，另存原量值及转换审计 |
| electrothermal_2d | 均匀电势场及DC/规定AC损耗→陶瓷+Ni单向稳态导热 | C/U/Emax、损耗、T/温升、热点/平均热阻，原始与离散热流诊断 |
| ac_eqs_2d | 真正复电势频域EQS；均匀或半高度共形两介质，Ni理想等势；可选热 | 复E/J、Y/Z、并联Cp、导电/介电损耗及可选T |
| electromagnetic_2d | 严格二维Ex/Ey/Hz Maxwell、有限电导Ni/陶瓷/无损空气、规定闭合引导端口；mu_r=1；可选热 | E/H/B/J、复端口Z/Y、陶瓷/Ni损耗、We/Wm、参考面内能量等效C/L及可选T |

电磁磁场不等于磁性材料模型：当前固定mu_r=1，不支持磁滞/非线性磁导率。电磁端口R/L不能直接称商业ESR/ESL；严格SRF、三维封装/PCB回流和开域辐射没有验收。

## CAD、网格与后处理

具备参数化二维叠层、电极阵列、重叠区/边距/保护层。原静电以陶瓷孔槽边界表示电极；电热/AC增加共形陶瓷+Ni热域及精确父子单元映射；AC可按半高度分区；EM增加有限Ni连通网络、接触柱和明确端口/空气范围。

Gmsh生成带语义标签的三角形网格；P1串行DOLFINx和PETSc直接LU，AC/EM在已有实数环境中用双实数块求复场。热源逐单元传递，核对功率；不把总损耗任意摊平。保留VTU场、MSH网格、扩展操作的XDMF/HDF5与NPZ映射、JSON指标/诊断/QC和可选PNG。图片注明二维及纵向放大，不能替代科学验证。

## Windows、单位与交互

沿用 Agent→Skill→固定Adapter→WSL科学环境→结构化结果/产物。Windows负责输入校验、单位边界、授权、任务、日志、结果与解释；WSL只做科学计算。没有安装/升级科学环境，没有旧前端、旧状态或来源路径运行依赖，也没有新增MCP/任务系统。

原SI静电与多单位静电接口不变。新三个 *_quantities 入口接受显式量值/单位/来源，经唯一公共核心(core1.0.0/catalog1.1.0)统一规范化，支持长度、电压、频率、电流、电导率、热导率、对流系数和绝对温度的白名单单位。旧SI入口仍可用；WSL始终只接规范化SI，详见[多单位交接](EXTENDED_UNITS_HANDOFF.md)。RMS/peak、损耗机制、热边界和EM端口必须明确。

公共入口支持preflight、run排队、worker一次执行、status/result/artifact只读查询。旧静电已完成gpt-6.1-sol/low真实两轮对话；新三项已完成公共Runtime端到端与方法Skill接入，未另做真实LLM对话验证，不复用旧对话冒充新证据。

## 本轮实际小算例

| 算例与工况 | 代表结果 |
| --- | --- |
| 原SI静电：6间隙、10/0V、1mm深度 | C=12.8931222502nF；本轮新回归results与原基线完全相同 |
| 规定DC电热：6间隙、sigma=1e-4S/m、定温端冷却、5μm网格 | P=9.707675873mW，最高温升1.918243721K |
| AC-EQS：6间隙、100kHz、10V RMS、5μm网格 | Cp=12.8930378104nF；Z=2.712376381−j123.382920129Ω；P=17.808610446mW；最高温升3.518994208K |
| EM：1间隙、1MHz、0.1A RMS、规定端口、2μm网格 | Z=0.873203906−j73.797785948Ω；P=8.732039062mW，其中Ni约0.467879438mW；最高温升5.324755598K |

以上是不同条件下的合成验证数据，不是同一实物的多物理标定。电热/AC已与原实验对应粗网格结果核对；扩展科学核的13个关键函数与来源AST相同。另真实运行了零损耗、规定AC峰值+Robin、双材料复场且关闭热等分支。

电磁5μm→2μm的原始梯度热流平衡误差从18.3%降至7.3%，仍未验收局部热流精度；不能用离散反力平衡接近机器精度掩盖。Emax受尖端/网格影响，只作诊断，不判断击穿安全。
