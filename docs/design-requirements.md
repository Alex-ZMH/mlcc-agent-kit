# 通用 MLCC 仿真计算系统：需求、任务与验收

版本：v002；更新：2026-10-21（Asia/Shanghai）。本文件落实用户对通用计算系统、正常设计性能与劣化分析并重的要求，是 [主计划](../PLAN.md) 的科学需求与验收依据；具体实施见 [执行交接](P0-P12-execution-handoff.md)。本次只修订规划，不代表新增能力已经实现。

## 1. 系统目标与案例身份

建设可复用的 MLCC 仿真计算系统：用户指定材料、晶相、组成/掺杂、结构、工况与计算目标，系统组织建模、DFT、性质计算、势资格、MD、结果分析及参数交付。在已验证方法、模型与工况适用域内，系统应能解释和预测正常工作时的材料与界面性能、比较设计方案、在给定设计要求时判断适配程度，并按目标分析劣化和失效机制。通用性指输入、流程与能力可复用，不承诺一个模型覆盖任意配方和条件。

系统不以发现损伤为成功条件，也不预设任一候选必然符合设计。正常、满足需求、接近边界、不满足需求和证据不足都必须是可表达的结果。没有产品合格线时，可以完成计算系统建设、真实案例验证、性能预测和方案比较；只保留具体设计达标判定未评估。

| 层次 | 定义与本轮约定 | 不能混同的结论 |
| --- | --- | --- |
| 系统能力 | 可配置建模、ABACUS 生产 DFT、四性质、合格势 LAMMPS、分析与条件性器件参数交接 | 一个材料算通不等于所有材料/方法均可用 |
| 工程 fixture | Ni 工程模型用于调度、MPI、输入输出、引擎迁移及单位数值检查 | 工程闭环不证明陶瓷或界面科学预测正确 |
| 已指定科学验证案例 | 无掺杂 CaZrO3、正交 Pnma、400–580 °C（673.15–853.15 K）、1 atm；保留已有 study 与来源审查 | 案例参数不成为系统硬编码默认或通用产品合格线 |
| 新指定铁电验证案例 | 用户已选BaTiO3未掺杂、中性、化学计量P4mm五原子原胞、极轴[001]；job361从有来源ZStar四方参考导入并绑定既有Study，Ti/O位移保留。压力/场/机械边界仍需具体任务声明 | 800–1350°C仍是工艺范围，不代表该P4mm工程基线的稳定温区；不从CaZrO3复制结果，不代表铁电科学资格已通过 |
| 其他能力验证案例 | 铁电、开壳层、缺陷、金属/陶瓷和聚合物场景，按所测能力选择有依据的小案例并记录适用范围 | 不能因 CaZrO3 不适用而把对应系统能力标为完成；不能擅自更换已指定案例 |
| 用户研究与设计规格 | 后续每个 study 自行给出材料/工艺/几何/工况，以及可选目标值、上下限与来源 | 未填写指标不等于材料不合格，也不阻塞独立的系统开发 |

手册重点是 BaTiO3 基高介电 MLCC，可作为机制与尺度分工背景；系统需按实际材料选择物理模型，不能把铁电畴、特定掺杂和工艺机理普遍套用。当前范围继续遵守 ABACUS＋LAMMPS 与参数交接边界；独立连续场、器件电磁及寿命统计求解器不因通用性要求自动纳入。

双案例具体执行、参考架构和开发批次见 [详细执行计划书](MLCC系统详细执行计划书-CaZrO3-BaTiO3-v002.md)。两案例按各自 selected_required_tasks 验收；系统其他能力继续在覆盖矩阵中保留。

## 2. 通用计算请求与场景

每个请求记录研究对象、目标可观测量、结构/方法来源、工况、对照方案、所需计算链和交付层级。可选择以下任务目的，允许组合：

配置字段为 selected_purposes，取值 normal、comparison、conformance、diagnosis；场景另存 selected_scenarios。两者分别表达任务目的与计算条件，不互相替代。

1. 正常工作性能计算：结构与相稳定性、电子/介电/磁/热/弹性及局部界面响应，输出数值、曲线、张量、机理和有效范围。
2. 设计方案比较：在可比工况下比较材料、相、掺杂、界面取向、聚合物角色或局部结构，不默认“数值更大”就是更好；多指标保留收益与代价。
3. 设计适配评估：用户提供要求后逐指标判断是否符合、裕量和适用工况。目标缺失时保留数值与比较，判定为 not_assessed。
4. 机制与边界分析：可解释正常稳定工作的原因，也可按目标研究偏离、劣化、迁移、滑移、开裂或脱层。缺陷存在本身不等于材料已劣化。

每个 study 按需要定义三类场景：

| 场景 | 目的 | 输入与结果 |
| --- | --- | --- |
| nominal | 正常工作与未损伤基线 | 指定温压、场/频率/载荷、相和实际结构假设；给稳态与可逆响应。正常制造组织允许包含有来源的晶界/缺陷，不能只用理想无缺陷晶体替代一切 |
| operating_boundary | 设计工作范围内的边界与裕量 | 依据用户给定范围选择温度、偏压、应变、界面约束等边界点；只有两温度点时不声称覆盖连续温区或等级认证 |
| diagnostic | 为机理验证或极限探索而设计的扰动 | 独立标记改变的缺陷、载荷、温度、速率或界面状态；与正常基线比较，不把额外极端条件当正常工况 |

所有温度、压力、材料、晶面和势从 study/任务输入读取。既有 400–580 °C（673.15–853.15 K） 与 1 atm 仅用于 CaZrO3 案例。机械外压不能替代氧分压；缺陷热力学另需化学势和热处理假设。电子展宽与晶格温度分开记录。

## 3. P0–P12 的系统建设任务

保留既有阶段编号和执行证据，扩展科学任务，不重置已经通过的工程门。

P4 的生产引擎/目标方法资格与新增科学工作包分开验收。后续链仅等待所需资格和实际数据，不等待全部缺陷、NEB 或界面功能。H1 仍验收迁移/生产资格，新增科学工具在 H2 或对应能力门下验证。

| 阶段 | 建设任务 | 正常性能与设计输出 | 条件扩展与验收 |
| --- | --- | --- | --- |
| P0 | Bundle、任务/结果记录及请求目标合同 | 可表达性能计算、比较、设计适配和机制分析 | 新需求合同单列待实现，不抹去已有 Bundle 安装证据 |
| P1 | LAN、Slurm、独立引擎环境与资源执行 | 真实提交、状态、日志、回传、取消 | 复用已验证基础设施，不为新计划重装或全量重跑 |
| P2 | 可配置材料/相/组成/掺杂/结构与场景建模 | 体相、表面、晶界、界面、可选聚合物的明确模型与谱系 | 纯母体、不同分布及补偿按请求构造；现有 CaZrO3 是科学验证案例 |
| P3 | VASP 工程基线 | 验证弛豫、SCF、E/F/应力和执行通路 | 已通过证据保留；不承担未来生产替代 |
| P4 | ABACUS 迁移、生产方法资格与公共物性/机理工具 | 晶格、能量、电子 DOS/能带/带隙、完整弹性张量、代表性表面/界面参考 | 缺陷形成/结合/偏聚、带电修正、NEB、注入势垒按目标启用；每个能力独立验收 |
| P5 | 介电与铁电响应计算 | 电子/离子介电张量、场/应变响应；适用材料的极化路径与铁电机制 | 温度响应需明确采样或有效模型；非极性案例不强求双阱，不替代铁电能力案例 |
| P6 | 自旋与磁性计算 | Ni/开壳层对象的磁态和磁性对电子、界面的影响 | U/SOC/交换按目标；非磁案例保留有依据的参考，不冒称磁性功能全部验收 |
| P7 | 声子与晶格热学 | 稳定性、声子谱、热容、热膨胀与目标晶格热导 | 谐声子、有限温度方法、三阶/BTE 或 MD 热导分别验收 |
| P8 | 电子热电输运 | 稠密能带数据桥、S、σ/τ、κe/τ、PF/τ 及适用条件 | 保留系统能力；没有热电目标的 study 不必执行，实际系数/ZT需 τ/κl |
| P9 | 同源扩胞、势选取/标注/训练和场景资格 | 正常温压/小应变与界面结合区的可靠能量、力和应力 | 分离、迁移、反应等按目标增加验证；界面 DFT 锚点先于相应势资格 |
| P10 | 体相及局部微结构 MD | 温度结构、密度、弹性恢复、热膨胀、局部稳定与热传输 | 条件迁移/缺陷/孔隙任务保留；无跳跃不能认定零扩散；不由短轨迹证明寿命 |
| P11 | 金属/陶瓷及可选聚合物界面 MD | 平衡连接、界面刚度、受载变形/恢复、滑移、热传递与适配比较 | 张开破坏、剪切极限、循环损伤为独立任务；机械收益与电气/热代价共同报告 |
| P12 | 结果分析、设计适配和参数交付 | 性能包、同条件方案比较、可追溯机理、逐指标结论及条件性器件估计 | 未达标诊断和证据需求；不把所有可选链绑成每个 study 的完成条件 |

### 3.1 P4 必须拆开的科学工作包

- **公共基线**：结构收敛；电子 DOS/能带/带隙及能量参考；独立应变、内部坐标约束、张量方向/单位和拟合误差明确的 Cij。工程小应变应力检查不等于完整材料弹性验证。
- **缺陷热力学**：形成/结合/偏聚能的定义、参考物与稳定化学势范围、相关电荷态、费米能参考、电荷中性与有限尺寸/势对齐方案。用来解释正常绝缘或劣化均可，不作为所有请求必跑项。
- **迁移动力学**：初末态与多条相关路径、NEB 图像与鞍点收敛、迁移/解离势垒；需要速率时补前因子及自由能/近似说明。结果交付局部动力学参数，不直接变成寿命倍数。
- **界面电子与力学参考**：终止面/取向/应变、界面数和面积、分离参考、局域电子态及必要势对齐。金属/陶瓷关注注入势垒，不能不加区分套用两半导体带阶定义。接口和本机能力逐项实测。

### 3.2 正常 MD 与破坏 MD 分开验收

先做目标工况下的平衡与未损伤响应，记录观测量、采样、独立种子、统计误差和可逆性；再按研究目标做较大载荷/极限过程。未破坏的正常工况轨迹是有价值的计算结果，但“没裂”本身不足以证明达到热、电、力全部设计要求。

合格势的正常适用域和破坏/反应适用域分别登记。新增元素、相、界面或聚合物环境后重新验证对应范围，不承诺存在覆盖任意 MLCC 配方的通用势。DFT 可逆分离功、MD 速率相关分离功、宏观断裂能继续分开。

### 3.3 必须落实的铁电第二部分与缺陷任务

[铁电与缺陷工作包](ferroelectric-and-defect-work-packages.md) 定义本轮补齐的输入、公式、依赖和验收。P2.20 按相态及工况路由；P9.19–P9.21 验证实际可极化/场模型；P10.14–P10.19 计算正常 P(T,E)、微分介电、电致应变与所需局部畴/翻转；P11.18–P11.20 处理合格模型下的界面电边界及局部响应；P12.18 交接实际计算量。当前净极化为零不自动排除局部有序或跨相变请求。系统铁电分支不能由非极性 CaZrO3 案例代验。

P4.18–P4.27 将缺陷热力学落实为模型/电荷集合、电子参考、化学势稳定域、带电超胞、屏蔽与修正、形成能/电荷转变、结合能、按需电荷中性/有限温度浓度、收敛和数据交付。缺陷作用可为正常补偿/稳定或劣化，按实际结果判断。修正所需 P5/P7 数据是具体任务依赖，不将全部缺陷研究变为 H1 总门。

## 4. 三种验收与结果判定

### 4.1 系统能力验收

按“能力 × 代表性案例 × 引擎/方法版本”登记 implemented_unverified、verified_in_scope、not_implemented、unsupported 四种能力状态，并附真实任务。完成安装、解析、物理基准和目标响应的验证是不同证据。无关的工程成功不填补科学能力缺口。

能力矩阵独立于单次 Result，记录 capability、capability_status、case_id、引擎/方法版本、证据与适用范围。案例验收另用轻量 case_validation 记录 study_id、case_id、case_role、所选必需任务、独立参照、科学有效性依据、结论与缺口。工程 fixture、科学验证案例和用户 study 的角色分开；无需新增工作流框架。

顺电介电、铁电极化、磁性、声子热学、电子热电、体相 MD、直接界面及聚合物分支分别保留覆盖记录。当前 CaZrO3 案例不适用的能力在系统矩阵中仍待相应案例验证；是否选定/运行新案例另按具体任务与预算推进。

### 4.2 科学案例验收

以指定材料和方法的结构、收敛、单位、独立参考、可重复物理响应与数据传递作为依据。CaZrO3 案例用于验证可适用的生产计算链；已有 Ni fixture 用于工程接线。不能将任一案例通过描述成系统已支持全部材料，也不能把没通过产品指标等同程序错误。

### 4.3 具体设计适配判定

结果记录保留三条独立信息：原生调度终态、scientific_status、design_assessment。需求模板见 [设计目标输入样例](../configs/design-targets.example.json)，是待实现的数据约定，不是现有运行工具已支持的证明。

| design_assessment | 使用条件 |
| --- | --- |
| met | 有明确需求和有效证据，工况/范围/对象一致，按约定误差处理满足目标 |
| not_met | 有效计算或独立数据支持该指标在指定工况不满足要求；保留数值与原因 |
| insufficient_evidence | 有目标，但缺必要物理、有效输出、条件覆盖、验证或误差跨越判定边界 |
| not_assessed | 未提供目标或尚未开展设计判定；性能计算可以已经完成 |
| not_applicable | 对该研究对象和需求确实不适用，附理由；不能代替系统能力的未实现状态 |

需求卡至少包括量/定义/单位、对象层级、比较方向、目标上下限、工况、必需性、来源与版本、容许误差或判定方法。所有未知数值保持 null，不以文献示例、代码测试值、X7R/C0G名称或现有案例温度补成普适规格。

裕量按指标定义：上限型为上限减结果，下限型为结果减下限，区间型分别给两侧裕量；同时附误差与适用范围。不混合不同单位打一个无依据的总分。误差区间跨界时按约定报告证据不足或进一步取样，不把点估计自动判通过。

设计级“满足要求”只针对全部适用且必需的已定义指标；未定义产品规格时不产生整机合格结论。科学上有效的未达标结果可以完成计算任务。计算失败或功能缺失不能作为材料不达标的证据。

Study 级聚合保留同一套 design_assessment：无规格或未开展判定为 not_assessed；任一适用且必需指标被有效证据证明不满足，整体为 not_met，同时保留其他证据缺口；没有已证不满足项、但必需项缺证据或误差跨界时为 insufficient_evidence；所有适用且必需指标有有效证据满足才为 met。全部指标物理上不适用时为 not_applicable 并说明理由；没有定义必需指标不能靠空集合判 met。可选指标不改变必需项聚合，但须单独显示结果和代价。

## 5. 依赖与首轮交付

1. 保留 H0 与 Ni 迁移小闭环证据；完成剩余 P4 数值方法/生产资格，不把小闭环升级为整个 H1 通过。
2. 实现通用请求、案例身份、适用性与结果/设计判定合同；数值目标可空，系统建设不等产品规格。
3. 用已指定 CaZrO3 案例贯通建模、ABACUS 公共基线、可适用介电/声子热学、同源扩胞与合格势体相 MD。具体源结构、温度几何和方法仍按真实证据完善。
4. 同时按能力准备其他代表性验证案例；CaZrO3 通过不能代替铁电、磁性、热电和异质界面分支验收。新案例不自动获得批量计算授权。
5. 对所选界面先给 DFT 锚点与势资格，再做正常界面响应、方案比较和按需极限/劣化分析。保留/临时高分子两条角色分别建模。
6. P12 可持续汇总；每个 study 按 selected_required_tasks 验收。可选 P6/P8 或未选择的聚合物分支不阻塞该 study，但未实现的系统能力继续登记为未完成。

每次交付报告系统能力覆盖与限制、案例结果与证据；再按 selected_purposes 与 selected_required_tasks 提供正常性能与机理、设计比较、可用的达标/裕量判定、异常分析及缺口。未选择的链不会被强制执行。DFT＋局部 MD 的材料参数与有条件的平板电容/等效电路估计分层呈现，不将单晶本征介电率直接当作任意多晶器件有效介电率。
