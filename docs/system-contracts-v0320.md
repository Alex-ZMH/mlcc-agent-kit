## 输入与输出边界

公共入口必须接收显式 method/site 路径及 `numerical_orbital_library` 记录：库名称、版本、PBE 配套声明、配套说明路径和逐元素 UPF 文件名映射。入口核对所选文件与映射和 `science.dft_functional` 的一致性；不替换输入、不自动调参，缺失或不一致保留原始错误。NAO 原生头只提供元素、截断半径、截断能、角动量上限和径向数等原生字段，PBE 来自声明的库配套记录，不伪称来自 NAO 头。

输出保留 `ssh_alias`、`method_set`、库及版本、配套来源、观测时间、逐元素原文摘录、UPF 配对信息、配套说明原文和映射原文。快照只建立输入来源和资格检查的可追溯性，不授予材料科学或生产资格。
