### 2.3 物理量和模型边界

1. D = ε0 E + P_total；相对微分介电张量为 εr,ij = (1/ε0) ∂Di/∂Ej。若模型只有离子极化，按一致定义补电子背景；若模型已含电子极化，不能再叠加同一 ε∞。采用涨落关系时说明系综、电边界、体积处理与充分采样。
2. Born 电荷线性位移估算 P 可用于经过验证的小扰动范围，不默认适合大幅翻转/相变；极化模型须处理周期分支和局部划分约定。仅输出几何偏心或颜色图不足以验证 P。
3. 外场动力学须同时有一致的场能量和场作用力/应力。后处理极化模型可支持特定零场统计，但不自动提供场驱动动力学。LAMMPS 提供若干可极化实现，不代表存在适用所有陶瓷/金属/聚合物的现成势。[LAMMPS 可极化模型](https://docs.lammps.org/stable/Howto_polarizable.html)、[core-shell 实现](https://docs.lammps.org/stable/Howto_coreshell.html)
4. 金属/陶瓷异质胞不套用整个胞的绝缘体 Berry 极化公式；电极屏蔽和开放/周期静电边界须由具体方法验证。没有合格电模型仍可交付已验证的界面力学/热学结果。
5. 多畴、小场可逆畴响应可属于正常工作；畴壁运动不自动等于损伤。大场翻转、极限加载与异常钉扎分别按请求启用。
6. 此链是局部原子/粒子计算，保持不做通用铁电相场、微米整层 FEM 或完整器件反馈的边界。有限温度极化模型的可行性有独立研究依据，但模型和数据需适配实际材料。[BaTiO3 能量与极化联合建模研究](https://www.nature.com/articles/s41524-022-00845-0)

所选缺陷若进入铁电 MD，P9.21 另验证对应缺陷/复合体、电荷与极化环境；P10.17 可比较正常缺陷偶极排列、局部极化和畴壁相互作用，以及按需钉扎/去钉扎。DFT 热力学电荷态不等同经典势中随意指定的点电荷；形成能/电荷中性结果不能自动转成 MD 中动态氧化还原。缺陷浓度、空间分布和是否冻结应作为明确模型输入，超胞周期浓度与稀释极限分开。

建议输出位于 workspace/results/<study_id>/ 下：ferroelectric-branch.json、polar-model-qualification.json、polar-response.csv、electromechanical.json，以及实际请求的 domain-wall.json、switching.json、interface-electrostatics.json。名称是规划约定；未执行文件不创建假结果。

### 3.2 统一公式、符号与参考

对体相、指定几何/方法下的 0 K 缺陷形成能，采用：

Hf(D^q; μ, EF) = E(D^q) − E(host) − Σi ni μi + q(EVBM + EF) + Ecorr。

- ni > 0 表示向缺陷胞加入原子；空位对应 ni < 0。q > 0 表示移除电子，q 以正元电荷为单位。结果记录公式版本、计量与符号，不只保存最终数。
- EF 相对同方法母体 VBM 定义；绝缘体扫描通常在所用方法的带隙内。EVBM、势零点和 Ecorr 使用一致约定。若非零压要求形成焓，另说明 pΔV 和结构/参考处理；有限温度自由能不能仅把此式改标签得到。
- 本文件将势对齐纳入 Ecorr 的总定义。若某实现把 qΔV 显式单列，则 Ecorr 的其他项必须去除同一对齐贡献，并保存分项，避免双计。
- 不比较跨引擎/赝势的裸总能。元素/竞争相参考与母体保持一致方法；分子和强关联参考若有修正须给来源及影响，不用未说明的常数拼接。

写 μi = μi^ref + Δμi，母相稳定要求 Σi ai Δμi = ΔHf(host)，对竞争相 j 要求 Σi bij Δμi ≤ ΔHf(j)，元素析出约束按相应参考满足 Δμi ≤ 0。有限 T 时一致替换相应自由能。竞争相集合和方法误差决定所得稳定域的有效性；若不存在稳定域，报告母体亚稳/参考问题，不人为制造区域。对于氧，μO = 1/2 μO2(T,pO2) 需明确气体参考及修正；机械外压 1 atm 不是氧分压。

EF 扫描和电荷中性求解是两个任务。扫描给出给定电子库的热力学曲线；平衡 EF 需载流子、缺陷及掺杂电荷共同满足中性。生长阶段缺陷数冻结后，测量阶段电子/电荷态可重新平衡，必须说明采用的物理假设。电荷转变能级来自修正后形成能曲线交点，不等同 Kohn–Sham DOS 缺陷峰或光学跃迁。

对组成守恒、qC = Σk qk 的复合体，约定：

Ebind = Σk Hf(Dk^qk) − Hf(C^qC)。

Ebind > 0 表示所定义反应下结合有利。反应组成或电荷不守恒时显式写原子/电子库，给出 μ/EF 依赖，不能省略库项后称“结合能”。同胞靠近/远离构型比较须保证等计量/等电荷和足够分离。结合自由能、0 K 结合能及 NEB 解离/迁移势垒分别输出；稳定结合不自动意味着迁移更慢或设计更优。

上述形成能、原子/电子库与缺陷平衡定义依据 [Van de Walle–Neugebauer（2004）](https://doi.org/10.1063/1.1682673) 和 [Freysoldt 等缺陷计算方法综述（2014）](https://journals.aps.org/rmp/abstract/10.1103/RevModPhys.86.253)；本项目将符号、方法和修正分项显式落到任务记录。

### 3.3 带电超胞修正与资格

- 对局域化体相点缺陷，根据晶格、介电各向异性与电势数据选适用 FNV 或扩展 FNV/eFNV。记录模型电荷、介电张量、远场参考及剩余有限尺寸误差，不能只套一个标量 ε 或只加一个 q²/L 项。方法依据为 [FNV 原始研究（2009）](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.102.016402) 和 [Kumagai–Oba 各向异性扩展（2014）](https://journals.aps.org/prb/abstract/10.1103/PhysRevB.89.195205)。
- 弛豫后的热力学形成能通常使用相应静态屏蔽；固定离子的垂直电子过程使用电子屏蔽或专门的垂直跃迁修正框架。不能把同一 ε 不加区分用于全部过程。
- 各向异性修正需输出坐标系和张量旋转；近铁电转变、强非线性或介电张量不稳定时，不直接把发散/无效 ε 塞入线性修正式。
- 不能将适用于三维体相的修正直接套到 slab、异质界面、金属或明显离域载流子。相应目标另列静电边界和修正方法资格；无法建立适用修正时报告限制。
- 验证至少包括修正前后的尺寸趋势、远场电势诊断、电荷局域化和方法敏感性；具体胞规模/阈值按精度与预算定义，不预设所有材料共用数值。
- ABACUS 的电荷、静电势输出及自旋/电荷局域化能力须用本机版本实证。[官方输出文件规范](https://abacus-develop.readthedocs.io/en/latest/advanced/output_files/output-specification.html) 只提供接口背景，不能认证本机 3.10.1；现有 Ni 中性工程环不证明带电缺陷链可用。
