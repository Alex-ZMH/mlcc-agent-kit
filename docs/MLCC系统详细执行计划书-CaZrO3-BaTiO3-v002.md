# 通用 MLCC 多尺度仿真计算系统详细执行计划书

## 以 CaZrO₃ 与 BaTiO₃ 为验证案例

版本：v002。编制日期：2026-10-21，Asia/Shanghai。项目根：`D:/project/mlcc`。

架构主要参考 Photoresist-agent-kit；功能实现定向参考 Photoresist-agent-kit 与 Autonomous Computational Scientist（ACS）；平台交付遵循本地 MatterAI `matterai.bundle.v2`。本书是当前执行计划的详细实施分册，沿用 P0–P12、H0–H4 和已有任务编号，新增内容不改变真实执行证据。

**交付目标：建立可复用的材料计算系统，用 CaZrO₃ 验证非极性陶瓷主线，用 BaTiO₃ 验证铁电及条件性相变/电场主线。系统能够计算正常性能、比较方案，并在未来获得具体规格后判断适配性；缺陷与劣化是可选择的机制研究，不是唯一计算目的。**

本书包含执行基线、架构与复用清单、数据合同、开发批次、两种材料的任务组、关键科学协议、资源估算、验收矩阵、决策清单及完整 P0–P12 子任务附录。案例配置和任务清单是规划数据，不是运行时已经实现的功能或已经计算出的结果。

配套附件：[完整任务索引JSON](../plans/mlcc-detailed-execution-v002.json)、[213项子任务CSV](../plans/mlcc-detailed-execution-v002.csv)、[CaZrO₃案例规划配置](../configs/cases/cazro3.validation-plan.v002.json)、[BaTiO₃案例规划配置](../configs/cases/batio3.validation-plan.v002.json)。上述附件本身不触发计算。v002 根据用户最新烧制温区修订案例；另交付 CZO firing-v002 派生执行study，原活动配置保持，执行窗口显式采用新配置。实际执行仍从现有资格与依赖继续。

### 1.2 案例身份与已知输入

| 对象 | 角色 | 已确认 | 本书中的未定项 |
| --- | --- | --- | --- |
| Ni | 工程 fixture；已有接线与引擎迁移证据 | 已有模型、VASP/ABACUS 工程记录 | 不承担陶瓷生产性质或完整磁性链验收 |
| CaZrO₃ | 非极性陶瓷科学验证案例 | 无掺杂、正交 Pnma 起始相；烧制计算温区 400–580 °C（673.15–853.15 K）；外压 1 atm | 生产方法/几何、势、缺陷物种与界面细节须逐项落实 |

BaTiO₃ 已由“可能的候选材料”升级为本次计划的确定案例，最新烧制温区已确认；候选四方相、低温能力验证点或缺陷集合不能升级为已确认生产输入。首轮可提出无掺杂四方 P4mm 与中心对称立方 Pm-3m 参考结构的对照方案；其实际约束、数值稳定性和有限温度适用性须记录。自由弛豫进入其他相时保留事实，不将被约束保留的相误称稳定基态。

本版以用户指定的烧制过程温区替换旧温度：CZO 400–580 °C（673.15–853.15 K），BTO 800–1350 °C（1073.15–1623.15 K）。区间内离散网格由本计划设计，并非用户逐点实测条件。两者均不是服役/测量温度，也不是 DFT 电子展宽。静态 DFT 保留 0 K 参考；目标温度几何与性质由经过适用性验证的非谐/热力学或 MD 方法产生。给定温区不单独证明能完成烧结致密化。

### 1.3 计算范围

第一部分包括：结构/掺杂/缺陷建模，ABACUS 电子与完整弹性基线，铁电/介电，适用的磁性，声子/晶格热学，电子热电，以及条件缺陷/NEB/界面 DFT 参考。

第二部分包括：同源扩胞与原子映射，势选型/训练/资格，LAMMPS 正常体相与局部微结构、力学/热学，合格极化模型下的铁电响应，陶瓷/金属及被选高分子界面，参数包和有明确假设的器件估计。

本次不建立通用 FEM、铁电/断裂相场、完整器件电磁或全电热力反馈求解器。尺度不能靠软件名称跳跃：局部 MD、0 K 分离功、速率相关 MD 加载功和宏观断裂韧性是不同量。两个陶瓷案例也不覆盖全部磁性、任意高分子或所有电极体系，缺项继续登记。

## 3. 参考架构与模块边界

### 3.1 分层职责

采用“薄Agent与领域Skill → 直接领域函数与持久任务 → 现有MCP/runner → Slurm → 科学解析与结果交接”的架构。Photoresist提供任务生命周期与科学交接的参考，ACS提供DFT作业、收敛与证据组织的参考。两套树都不成为MLCC运行时依赖，也不直接部署它们的完整服务。

| 层 | MLCC职责 | 当前状态与改造 |
| --- | --- | --- |
| MatterAI | 会话、Bundle装载、工具发现与调用 | 已验证原版非桌面runtime；保持bundle.v2 |
| Agent/四Skill | 理解目的、选择分支、解释方法/限制 | 保留结构/DFT/性质/MD四项；按功能完成更新说明 |
| 科学领域函数 | 建模、输入、解析、性质、势/MD和统计 | 已有modeling/vasp/abacus等；缺陷/极化等按阶段增量实现 |
| 任务与来源 | Study、Model、Method、Task、Result及轻量任务组 | 扩展现有tasks.py；任务组只存当前科学链的成员/依赖 |
| 工具和站点 | prepare/transfer/submit/query/cancel/collect | 七MCP与SiteRunner继续复用；所有数值任务走Slurm |
| 验收和报告 | 科学可用性、能力/案例/设计结论、参数交付 | 不把提交回执、文件存在或单个success字段当科学证明 |

TaskGroup只是有名称的普通任务集合与依赖表，不建设通用DAG平台或新数据库。不为了参考系统有某文件就逐一建立registry、store、status、receipt等新层；相关逻辑优先放在现有tasks.py和具体领域模块中，确有规模需要才拆文件。

### 3.3 用户入口与数值执行层

Photoresist当前0.3.7产品manifest的`mcpServers`为空，主要由公开脚本和独立Worker推进；其旧MCP材料不代表当前运行结构。MLCC已经完成MCP接线，采用相同科学分层不要求复制相同传输接口。高层领域函数可以在现有工具与runner上组合任务，必要时再通过新Bundle版本暴露新的公开接口。

现有工具为list_tasks、prepare_calculation、transfer_calculation、submit_calculation、query_calculation、cancel_calculation、collect_calculation（实际工具名均有`mlcc_`前缀）。查询返回实际Slurm状态，收集负责回传明确输出；数值收敛和物理有效性由确定性解析/领域函数判断。

大数据和长时间运行不依靠语言模型持续轮询。单个数值作业在Slurm中继续执行；工作流下一步骤由明确续接触发。若将来需要会话结束后自动推进多个步骤，再单独设计操作员启动的可选执行服务，不能把目前的持久记录描述为已经具备无人值守推进能力。

### 3.4 与参考系统保持的差异

- Photoresist的自动包装步骤重试、MD失败后数值恢复、工作区哈希命名和部分请求/结果复用不进入MLCC实现。
- ACS的Web、ADK循环、HTTP API、数据库worker、默认端点及重启/杀进程脚本不部署；使用其功能设计不需要重建整个服务栈。
- 无论上游如何组织目录，MLCC科学数据始终在workspace，参考树只读，站点/解释器/MPI/授权资源由私有配置提供。
- 功能存在、测试通过与科学有效性分开。参考系统的历史验收和fake harness只证明对应范围，不能转记成MLCC案例通过。

### 3.5 架构验收的最小闭环

用现有真实Ni记录演示“模型→方法→任务→job→输出→解析”的只读来源链，验证对象身份与原始错误保留；再在P4相应资格和案例输入满足后，通过CZO的一个ABACUS科学任务做真实衔接。BTO在独立确认的模型/方法上增加极化参考任务。DFT极化计算依赖引擎能力与绝缘参考，不要求先有MD极化势；有限温度/外场MD才依赖P9模型资格。

缺陷形成能的闭环则把host、缺陷q、元素/竞争相、VBM、介电与电势修正作为多来源任务消费。不能让一个最终标量遮蔽任何缺失上游，也不能以静态DFT温度标签冒充已完成有限温度计算。

### 4.2 单位、坐标与跨引擎交接

1. 统一约定结构长度 Å、DFT 能量 eV、力 eV/Å，并保存原生单位和转换依据。应力统一报告 GPa，明确拉伸/压缩符号与 Voigt 顺序；不能将 ABACUS、VASP、LAMMPS 的原始 stress/virial 直接拼接。
2. 极化使用 C/m²，电场 V/m，位移场 D 使用 C/m²；相对介电常数与绝对介电率分别命名。工程应变的剪切因子、晶体坐标到实验坐标旋转要明确。
3. 原胞→常规胞→超胞保留整数基变换、parent_atom_id 与 image_index。core-shell 等额外自由度需独立 particle_id 与对应原子，不伪称全部粒子都是原始原子。
4. 形成能/结合能以每缺陷或每反应事件计；表面/界面量记录面积和界面数，不能混用 eV/胞、J/m² 和 eV/原子。

6. `source_task`、job ID、记录 ID 各司其职；不拿 MatterAI 会话 ID 冒充计算任务或 Slurm ID。大型数组引用实际数据文件，不由语言模型复制改写。

### 4.3 缺陷结果的专用字段

## 5. 计算工作流与执行语义

### 5.1 一次研究请求的标准路径

1. 解析研究目的与案例，复用已确认信息。列出缺少且会改变物理问题的输入；无设计阈值不阻塞正常性能。
2. 选择实际需要的任务，检查每个任务依赖的模型、方法和资格，形成所选任务清单。
3. 准备有版本的模型和输入；返回原子数、方法、预测任务量、资源与停止点。准备完成不等于提交。
4. 在已有授权范围内逐项调用 prepare、transfer、submit；记录提交意图和 sbatch 原生回执。提交结果不明时先核对真实调度，不盲目重新提交。
5. query 查询 Slurm；list/status 的保存快照必须附时间，不代替实时 query。取消请求与调度确认分别记录。
6. collect 保存真实输出，再由引擎/性质解析函数检查电子、离子、力、应力和目标 observable。
7. 对通过相应资格与科学检查的结果推进下游任务；失败保留原错误。用户/执行者显式修改方法后建立新版本任务，不自动重试。
8. 汇总正常性能、比较结果和条件分析。请求追加分析时引用原轨迹/结果，不启动新数值任务；数据不支持目标量时说明需新增的计算。

### 5.2 三种状态不能混用

| 维度 | 回答的问题 | 示例 |
| --- | --- | --- |
| 执行事实 | 程序在哪里、是否运行完 | Slurm RUNNING/COMPLETED/FAILED、退出码、回执与时间 |
| 科学有效性 | 输出是否支持本次物理结论 | SCF 收敛但势不覆盖界面时，不能输出合格界面预测 |
| 设计适配 | 是否满足用户给定指标 | 无规格为 not_assessed；有效结果明确超限才可为 not_met |

系统能力、科学案例也有独立验收记录。一个未达设计目标的有效结果可以完成科学任务；一个计算失败不能判材料不达标。单个指标的物理不适用不等于全部案例或系统能力已通过。

### 5.3 继续、暂停和失败处理

同 task ID 的重复“继续”首先读取事件与原生回执。已提交任务查询原 job；已完成步骤直接消费原产物。阶段停止点是工作流边界，不代表引擎具有断点续算能力。真正 checkpoint 续算须验证求解器文件、参数一致性和支持方式，本计划不默认实现。

不复制 Photoresist 的自动减时间步、延长平衡、额外 NVT/NPT 恢复或 dispatcher 重试。数值失败可提出下一次明确实验方案，原失败保留，协议变更用新任务记录。原始错误不被概括性“可恢复”标签遮蔽。

## 7. CaZrO₃ 与 BaTiO₃ 双案例执行方案

### 7.1 目标、范围与案例身份

1. 以两个物理性质不同的陶瓷案例贯通同一套建模、ABACUS DFT、性质、势资格、LAMMPS MD、结果交接和设计判定接口。
2. CaZrO₃ 是已确认的非铁电验证案例：无掺杂、正交 Pnma 起始相、烧制计算温区 400–580 °C（673.15–853.15 K）、外压 1 atm；高温相态另行验证。
3. BaTiO₃ 是用户确认要执行的铁电能力案例；其烧制计算温区 800–1350 °C（1073.15–1623.15 K） 已确认；高温相、外压/机械边界、电场、掺杂和缺陷集合尚未确认。高温正常响应与低温铁电能力基准分开。
4. 两个案例均以 `normal` 正常性能为主线，保留 `comparison` 与 `diagnosis` 的任务选项；`conformance` 只在给定规格后判定。缺陷、迁移或畴结构本身不自动归为劣化，场景由所研究的正常机制或额外扰动决定。
5. 没有产品规格时，输出性能、误差和适用范围，`design_assessment=not_assessed`；不得用文献示例、X7R/C0G 名称或案例温度补出普适合格线。
6. 案例通过只证明相应材料、相应方法和相应工况的证据；CaZrO₃ 与 BaTiO₃ 不等于整个系统已覆盖所有铁电、缺陷、界面、聚合物和开壳层能力。
7. 所有任务使用现有 `VASP→ABACUS` 迁移和 `sbatch→实际 Slurm 状态→collect` 路线；不从参考树复制代码，不自动重试或切换引擎。

### 7.7 首批最小执行集与扩展集

缺陷能力的小闭环建议先对两材料分别列出氧空位的非等价氧位点与q=0、+1、+2候选，逐一核对电子数、自旋与局域化，不能将全部候选假定为稳定电荷态。结合能验证可另提无外来掺杂的A位空位—氧空位复合体：A=Ca或Ba，孤立与复合反应组成/总电荷守恒，比较多个距离/取向与远分离对照；具体q和结构必须通过母体电子结构与带电方法资格确认。这是最小方法验证候选，不是已确定真实器件中的主导缺陷，也不授权全组合提交。

## 8. 公共 DFT、力学与热输运实施协议

### 8.1 结构与方法资格

来源核对包括结构数据库/文件版本、化学式、占位、晶胞选择、原子顺序及相标签。分数占位必须变成明确整数构型后才能开展相应显式缺陷计算。用户选择的 k 规则保持 `ceil(30/a), ceil(30/b), ceil(30/c)`（Å）；它是采样规则，不冒充完成了独立 k 收敛研究。若目标性质需要更密网格，先列明原因及新方法版本，不能默默更改。

对每种材料分别检查泛函、价电子范围、赝势/基组、展宽、自旋、色散与目标响应能力。Ni 的 100 Ry 工程参数不能自动作为 Ca/Zr/O 或 Ba/Ti/O 的最终参数。记录固定胞离子弛豫、变胞弛豫、对称性约束和残余应力；采用约束参考相时单独标记。

方法资格包括实际二进制和输出解析；最新官方文档只作方法背景。ABACUS 3.10.1 缺功能时给出明确升级/开发或该链待实现记录，禁止静默调用 VASP。VASP 的已授权资源始终不进入 Bundle。

### 8.2 电子结构与绝缘参考

任务顺序：合格结构 → SCF → 与该方法一致的能带/DOS计算 → VBM/CBM/带隙/投影态结果 → 定义有效参考。记录 k路径与能带窗口、网格、展宽、自旋通道和能量零点。总 DOS、投影 DOS、热力学电荷转变能级和光学跃迁是不同输出。

半局域 DFT 带隙误差在缺陷和输运解释中单独讨论；需要高阶泛函/修正时先验证本机方法及参考一致性。不得靠直接平移 DOS 图掩盖电子库与缺陷能修正问题。带隙不直接给器件额定耐压，DOS 不直接给泄漏寿命。

### 8.3 完整弹性张量 Cij

1. 明确静态零温、有限温度或有限速率响应；选择 clamped-ion 或 relaxed-ion，晶胞和内坐标约束写入任务。
2. 依据实际对称性设计独立应变。先检查母体的残余应力，再施加成对正负小应变与至少两种幅度，完成应力—应变拟合及线性区验证。应变幅值为方法试验参数，不能事后挑选最有利拟合。
3. 输出完整 6×6 Cij、Voigt顺序、剪切约定、坐标、单位、拟合误差及独立构型来源。可用对称性约化，但要保存独立数据和重建关系。
4. 若实际为正交晶体，通常有9个独立弹性常数；四方 4mm 常见6个，立方常见3个。若缺陷/应变降低对称性，则按实际结构处理，不能强行套母相矩阵。
5. 检查张量对称性与所选应力条件下的稳定性，有限外压时使用相应稳定性判据。Voigt/Reuss/Hill模量是后处理，不代替完整张量；工程应力正负号校准也不代替 Cij。

### 8.4 介电、Born 与声子

Berry 极化比较沿连续绝缘路径处理极化量子；绝对输出值不能不解分支直接相减。Born有效电荷、电子介电 ε∞、力常数与离子介电来源分别记录，分开钳制/弛豫及频率极限。

有限位移力常数遵循原子映射、位移幅度、超胞与力精度。报告声子色散、DOS、声学和规则及必要非解析修正；数值小负频与真实软模分别分析。高对称 BTO 的 0 K 不稳定模式可能是研究对象，不能为了“通过”任意截掉虚频，也不能把不稳定谐模型的热力学量照搬到有限T稳定相。

QHA 仅在所选体积/温区的模型适用时使用。强非谐/相变区域需要适当有限温度采样或另行资格化方法；没有方法时保留缺口。谐声子热容/自由能与晶格热导不是同一任务。

### 8.5 晶格和电子输运

- BTE 路线：二/三阶力常数、截断/超胞、q网格、散射项与求解收敛分别验收；三阶力任务先预算数量。谐声子通过不表示 κl 已完成。
- MD 路线：Green–Kubo 或 NEMD 按势和几何选择，核实长程/多体热流定义、体积、热浴、时间窗口、长度与统计收敛。使用相同目标状态比较，界面热阻与体相热导分开。
- 电子热电：ABACUS→BoltzTraP2 等桥接需要实际能带/速度或对应方法数据。τ未知时报告 S、σ/τ、κe/τ；不把τ设成任意常数后称预测电导。ZT需要同条件τ与κl，张量方向先定义。
- Ni电极的晶格热导不等于总热导。CZO/BTO作为绝缘基线不要求强行产出“优良热电材料”结论；通用接口保留，适用性及载流子条件明确。

### 8.6 磁性能力

按实际电子结构选择非磁/自旋极化参考及合理磁态，记录初态到终态的磁矩与能量。纯净 CZO/BTO 可以得到有效的非磁参考，不强造磁序；缺陷或未来掺杂出现局域电子时再开展相应自旋/U/SOC资格。已有Ni工程自旋结果不能自动完成交换、各向异性或稀土f电子的通用能力验收。

### 9.2 公式与符号

Hf(D^q; μ, EF) = E(D^q) − E(host) − Σi ni μi + q(EVBM + EF) + Ecorr。

ni>0 表示向缺陷胞加入原子；q>0 表示移除电子，q以元电荷为单位。EF相对同方法母体VBM定义。此式按本书约定表示指定几何/方法下的0 K能量框架；非零压形成焓须处理pΔV，有限T自由能须有实际自由能贡献，不能仅改标签。

Ecorr包含采用方法的对齐项。若实现单列qΔV，则其他修正项不得重复计入。保存所有原始项，形成能后处理可以重复计算不同μ/EF而不重跑同一DFT任务，但必须在方法/参考适用域内。

μi=μi_ref+Δμi；母相满足ΣaiΔμi=ΔHf(host)，竞争相满足ΣbijΔμi≤ΔHf(j)，元素析出约束按相应参考定义。氧库由1/2 μO2(T,pO2)建立，气体参考与方法修正明确；机械压力1 atm不是氧分压。稳定域不存在时报告参考/相稳定性问题，不能人为拼成“富氧/贫氧”窗口。

Ebind = Σk Hf(Dk^qk) − Hf(C^qC)，当反应组成守恒且qC=Σqk时，正值表示所定义结合反应有利。μ和EF项在守恒反应中抵消；不守恒时明确保留原子/电子库。形成/结合有利与器件设计有利并非同一判断。

费米扫描不是电荷中性求解；热力学转变能级不是DOS缺陷峰。生长缺陷浓度冻结与测量温度电荷态再平衡须分开。完整方法与来源见 [铁电与缺陷工作包](ferroelectric-and-defect-work-packages.md)。

### 9.3 带电修正的实现顺序

先用本机ABACUS小任务确认电荷计数、补偿背景、电势/密度输出及局域化，再实现修正适配器。对各向异性体相局域缺陷选择适用FNV/eFNV，保存张量坐标、模型参数、远场取样和剩余有限尺寸误差；不能只加固定q²/L项。

热力学弛豫态通常对应静态屏蔽，固定离子垂直过程需电子屏蔽或专门框架。近BTO相变强非线性、无效/发散介电、slab、金属化或离域载流子不能直接套三维线性体相修正。至少做不同尺寸/形状趋势与远场诊断；修正后看起来平滑不自动代表模型正确。[各向异性修正方法](https://journals.aps.org/prb/abstract/10.1103/PhysRevB.89.195205)

### 9.4 NEB 与速率

NEB任务先固定初末态的组成、q、相、应变与电子方法，确认端点弛豫及原子映射；枚举物理不同跳跃方向，不把极化路径与氧空位迁移路径混为一类。保存插值策略、图像数、切向/垂直力、鞍点收敛及反向势垒。图像数收敛是方法任务，不把任意5/7图像设为普适合格线。

仅在需要速率时进一步建立振动前因子或相应自由能方法，报告k(T)=ν(T)exp[−ΔG‡/(kBT)]的假设。负模、约束、缺陷态与路径维数明确。0 K势垒、有限T自由能垒和解离结合能分别输出；单个势垒不能转换为MLCC寿命。改变电荷态的路径不沿用固定q NEB的速率解释。

### 9.5 界面 DFT 锚点

先选陶瓷终止面、Ni取向、面内匹配与应变分配、化学计量、电荷/极化和边界；再计算registry、间距、分离/剪切等所需锚点。片段参考保持一致面内胞、组成和约束，明确单/双界面计数。电子界面研究另做电势对齐、局域态与适用的带阶，不把金属费米面与绝缘体整体Berry极化混用。

锚点先于对应P9界面势资格；P11只消费已生成参考，不能形成“先做界面MD再证明势”的循环。未选择具体界面时可实现构建/解析模块，不自动生成用户未确认的表面化学结果。

## 10. 铁电第二部分与正常 MD 协议

### 10.1 按物理目标选择模型

| 请求 | 最低模型要求 | 验收重点 |
| --- | --- | --- |
| 无场结构/力学/热学 | 覆盖相、温区和加载的E/F/应力势 | 结构、相对能、弹性、热流/积分等目标验证 |
| 零场极化统计 | 上述势与经验证的极化定义/模型 | 周期分支、P与局部序参量、采样和来源 |
| 小场介电/电致应变 | 一致场能量、场力/必要应力与电边界 | 双侧扰动、幅度依赖、力和能量一致性 |
| 跨相变/畴/翻转 | 覆盖相关相、局部结构、长程与场历史的模型 | 独立温度/尺寸/历史、相态与极化响应 |
| 陶瓷/金属界面电响应 | 额外屏蔽、电势/电荷边界和界面参数 | 去极化、场分配、终止面与电极模型资格 |

LAMMPS具有可极化实现类别，但任何一个包的存在都不证明存在合格的BTO或陶瓷/Ni参数。可选core-shell、带显式电荷/偶极或可微场耦合模型；有效哈密顿量只有在确认实际实现和执行后端后才能进入任务。[LAMMPS可极化模型说明](https://docs.lammps.org/stable/Howto_polarizable.html)

BaTiO₃ 的能量模型与极化模型联合路线有原始研究示范；该研究也指出相变温度准确性受DFT参考影响。因此本书要求验证当前ABACUS参考和选定模型，不能把文献温度照抄成模型验收结果。[BaTiO₃联合建模研究](https://www.nature.com/articles/s41524-022-00845-0)

### 10.2 正常体相的先后顺序

同构型模型核对 → 时间步对照与短NVE漂移 → 合适机械边界的平衡 → 平衡诊断与生产采样 → 独立副本 → 结构/密度/弹性/热响应 → 尺寸、时间及误差分析。若有core-shell额外自由度，温控与时间步按实际质量/频率模型验证；普通原子NVE协议不能未经核对照搬。

正常输出至少包含本次已选的observable及其恢复/可逆性或波动范围。材料稳定、无损伤、低漂移或有利缺陷组合都可以是有效物理发现，但没有用户指标时不宣称“符合设计”。高场翻转、极限加载和裂纹/脱层仅作为被选择的分支。

### 10.3 极化与微分介电

D=ε0E+P_total；相对微分介电为εr,ij=(1/ε0)∂Di/∂Ej。记录工作点E0和双侧小场幅值，至少检查幅值线性区与采样敏感性。不能在非线性偏压下用P/E替代微分介电；电子背景与模型已有电子极化不得重复叠加。

局部P须有明确空间划分/原子到局域单元映射；全局P为零可能来自对称相、热采样或多畴抵消，不能单独判非铁电。Born电荷位移近似先验证适用的小位移范围，不默认适合大幅翻转。平衡涨落法注明系综、电边界、体积和采样条件。

### 10.4 温度、畴和场历史

先在选定温度点验证稳定采样，再决定是否作升/降温与相变加密。保存不同初态与历史，区分有限尺寸、动力学冻结和真正热力学相变。候选相在0 K谐近似下失稳，不等于有限温度统计已经可用；二者分别验收。

局部畴/畴壁的取向、数目、面积、电荷与边界显式给出。0 K超额能和有限T自由能不能混名。P–E环须记录频率/速率、场幅、循环与尺寸；MD高频环不能直接命名为实验矫顽场、kHz损耗或长期老化。

### 10.5 界面与高分子选择

陶瓷/Ni先验证正常连接、可逆剪切/恢复、热流和局部结构，再做被选择的破坏加载。铁电界面额外核实屏蔽、去极化、场分配与极化取向。无法验证电模型时可交已有力热学结果，但电学分支仍未完成。

保留高分子层与临时粘结剂/排胶后状态分为不同模型；前者需要真实化学、链长/交联/含水等条件及有机—无机交叉作用，后者需要实际残留/孔隙结构，不能用“删掉聚合物”代替所有工艺。Photoresist的有机建模/映射只作为被选高分子分支的功能参考，不自动解决陶瓷/金属交叉势。

### 11.3 起始试验与扩大条件

普通MD可从1个较小体系的稳定性试验开始，再提出3个独立速度种子的首轮统计方案；3不是普适充分样本数，也不用于替代独立缺陷构型。时间步先提出Δt与Δt/2对照，平衡/生产长度由自相关与稳定性诊断确定；不能在结果出现后自动改变协议重跑。

缺陷超胞优先从能区分周期像相互作用且可承受的整数矩阵候选开始，列实际原子数和最近像距离；例如20原子常规胞的2×2×2为160原子、5原子胞的同扩胞为40原子只是计数示例，不是已选生产规模或足够收敛的承诺。不同相/方法先核对实际母胞，避免按化学式猜原子数。

计算成本超过已明确批次范围时，先交付构型/任务清单、单任务实测、总资源与取舍；不能后台无限提交。数值失败、科学不稳定和材料不满足某设计指标分别处理，不为了赶预算降低物理要求。

### 12.2 三类验收对象

系统能力按“功能×代表案例×引擎/方法×适用范围”覆盖。案例验收只检查本案例已选必需任务及独立参考。设计验收只有目标给出后才进行。无规格时，系统和案例可以通过，设计仍not_assessed；不能为了让报告全绿而伪造指标。

Study级聚合：存在必需且适用指标的有效不满足证据，保留not_met；否则必需证据不足为insufficient_evidence；全部必需适用项有效满足才met；无规格为not_assessed；全部物理不适用也不能自动met。误差跨合格线时不给武断通过。

### 12.3 数值容差的建立

容差按目标物理量、模型用途、独立参照和可承受误差在批次运行前登记。SCF能量/力阈值、截断与应变收敛、势E/F误差、极化/介电误差、统计区间和设计阈值各自独立。Ni工程力阈值不成为所有材料的普适阈值。只有训练RMSE小不能证明界面、相变或长程电边界合格。

每份资格报告列：误差目标及来源、测试数据、实测误差、敏感性、适用域、未通过项、原始文件。有限范围验证只能标记verified_in_scope，不能扩成任意材料/工况都支持。

### 12.4 验证尺度与声明范围（VALIDATION-01）

手册第25页的数值、材料/组织、器件/安装、可靠性/外推是证据适用层级，不替代本书“系统能力、科学案例、设计适配”三类验收对象。只声明某一层结论时，必须具有该层所需证据：数值收敛不证明材料模型准确，材料样片参考不证明安装后器件响应，单个轨迹/样品不证明寿命概率。

- [ ] P6.01 列出磁性对象与目标：总/局域磁矩、自旋态差、各向异性、交换或对介电/界面的影响。非磁陶瓷设置必要参考即可。

- [ ] P6.03 构建合理初始自旋构型和超胞，记录原子—磁矩/方向对应。比较能量时保持可比方法及说明几何是否相同。
- [ ] P6.04 计算并核实最终磁态，而不只按输入 MAGMOM/初始方向给模型命名。记录局域定义与总磁矩、收敛情况和亚稳态。
- [ ] P6.05 目标需要才做 SOC 方向能、交换映射或磁各向异性，检查其精度是否高于相应能差；不由少量态差自动推出居里温度。
- [ ] P6.06 对掺杂/缺陷做合理的电荷、自旋、结构关联分析，不把磁性、铁电和热电视为同一个性质。
- [ ] P6.07 给 P9 标注链说明自旋处理：普通坐标 E/F 势不自动含显式自旋自由度，混杂自旋分支可能造成同几何多值标签。限定目标磁态/温区，不能默认能处理磁相变。
- [ ] P6.08 输出 magnetic.json、自旋构型、必要 SOC/交换数据与图、方法/有效范围和不适用说明。

完成门 G6：最终态与电子模型支持被报告的磁性量。经验证的非磁基态或零自旋磁矩可以是有效结果，不因没有开壳层就把整个案例判为不适用；特定磁序/交换子任务确实不适用时才附理由标记 `scientific_status=not_applicable`。磁性任务未选择或未计算时只记录执行事实。未选择磁性任务不等于磁性系统能力已通过，通用能力仍需代表性开壳层案例的独立证据，不虚构磁性结果。

### A.8 P7：声子与晶格热学任务链

输入：ABACUS 弛豫模型、有限位移力接口；极性修正需 Born/ε∞，热导需更高阶信息。

- [ ] P7.01 确认模型稳定相、温度背景、超胞尺寸及目标。0 K 软模与高温稳定相的关系预先说明。
- [ ] P7.02 用所选 Phonopy 版本生成位移结构与位移清单，保存唯一顺序和母模型映射。掺杂降低对称性后重新统计实际任务量。
- [ ] P7.03 生成全部位移力任务，但先打印任务数、每任务原子数和预算。大掺杂胞再扩声子超胞可能超出资源，不能直接满量提交。
- [ ] P7.04 位移态只求力，不重新结构弛豫；统一电子精度、k 密度、自旋和方法。核对漂移/平移不变性及力的数值精度。
- [ ] P7.05 按真实顺序收集位移力，计算二阶力常数。若施加声学和规则/对称化，记录原始与处理后的差异，不用它隐藏严重数值问题。
- [ ] P7.06 计算色散、DOS、软模与本征矢，检查 q 网格、超胞、位移幅度和小负频的数值来源。真实不稳定模不删、不取绝对值。
- [ ] P7.07 极性非解析修正与 P5 共享同模型 Born/ε∞，核对张量和原子顺序。缺数据时报告未做 NAC，不能默认为完整极性谱。
- [ ] P7.08 对稳定相做可适用的 Cv/自由能和必要 QHA 热膨胀；区分 Cv/Cp。强非谐/高温稳定相先定义相应方法，不直接套谐波公式。
- [ ] P7.09 对筛选后的代表性材料做三阶力/BTE κl，先统计位移数和收敛成本，不对每个随机掺杂构型无预算展开。若明确选择 MD κl，则此子项只定义交接和适用条件，实际计算必须等 P9 势资格/P10 热流与尺寸验收；不得在 P7 提前跳过这些依赖。
- [ ] P7.10 说明缺陷散射、同位素、有限晶粒和实验微结构是否包含，避免把理想晶体 κl 直接叫器件总热导。Ni 总热导还含电子项。
- [ ] P7.11 输出 force constants、位移/力文件、phonons.json、thermal-lattice.json 和参数交接。给 P5/P8 的引用指向具体模型/方法任务，不指向无版本的目录。
- [ ] P7.12 完成位移顺序、单位、可重复频率/热学基准和物理收敛测试，附全部 job ID 与失败/未提交列表。
- [ ] P7.13 对正常工况和 comparison 请求交付可用性能输出（稳定相、Cv/Cp、热膨胀、声子 DOS/群速度、κl 或明确的替代量），不能把“查找虚频”当作阶段唯一目标。温度、方向、边界、采样和误差必须随结果保存。
- [ ] P7.14 将虚频分成数值误差、真实 0 K 不稳定和有限温度稳定性问题，分别给出后续动作；虚频或无损轨迹都不能单独决定 `design_assessment`，应回到目标指标和适用方法。

完成门 G7：谐声子和 κl 分开验收；只有色散/DOS不算热导完成，有真实高温软模也不等于软件链失败。

### A.9 P8：电子热电输运任务链

输入：ABACUS 稠密均匀 k 能带、自旋/电子数/晶格及输运条件；真实系数与 ZT 另有依赖。

- [ ] P8.01 明确本链是 Seebeck/电子输运，不是声子热导、自热或磁性。确定 T、化学势/载流子范围与绝缘体研究的物理目的。
- [ ] P8.02 用合格 SCF 和稠密均匀 k 采样产生能带；高对称路径 band plot 不能直接当输运积分输入。
- [ ] P8.03 固定 BoltzTraP2 版本，查该版本实际数据接口。实现 ABACUS 数据桥，不宣称存在已验证原生读取器。
- [ ] P8.04 转换晶格、k 坐标、能量零点/单位、电子数、自旋通道及必要对称信息。用解析或已知数据集和独立数值对照验证，不只检查“文件能打开”。
- [ ] P8.05 做插值与密 k/能带窗口收敛，确认简并、自旋/SOC等输入与所选后处理方法兼容，不能把不支持的数据结构硬塞进结果。
- [ ] P8.06 报告刚性带和常数散射时间近似及其限制，输出 S、σ/τ、κe/τ、PF/τ 的张量/方向、T 和 μ/浓度约定。
- [ ] P8.07 给定有来源的 τ 后才输出 σ、κe 和 PF，明确使用何种张量/方向定义。τ 未知就保留归一化结果，不填一个“典型值”冒充预测。
- [ ] P8.08 根据所选路线等待同状态/方向的具体 κl 任务：P7 的 DFT/BTE，或 P9 合格势之后 P10 的 MD 热导。后一条的完整 ZT 必须推迟到相关 H3 结果完成后；此前只验收不依赖 κl 的输运子项。张量情形先定义测量/边界方向，不把所有分量直接当标量套除法。
- [ ] P8.09 讨论带隙误差、缺陷能级/载流子与绝缘漏电代价；高电导/高热电性能不等于 MLCC 更可靠。
- [ ] P8.10 输出 transport.json、T/μ/浓度表、桥接输入/输出、单位测试、收敛证据和未确定参数。

完成门 G8：tau 归一化与实际系数分开；没有 τ/κl 时不把 ZT 标为完成。

### A.10 P9：同源扩胞、力场资格与训练

输入：ABACUS 弛豫母模型、MD 目标和对应 DFT 方法集。扩胞只是几何操作，不会自动创造合格相互作用。

- [ ] P9.01 读取 P4 的明确 model/version，不从 VASP 旧文件或“最新结构”偷偷取父模型。为界面列出陶瓷和 Ni 两个或更多父模型。
- [ ] P9.02 用 ASE 整数矩阵扩胞，输出原子数/计量/晶格与 parent_atom_id＋image_index→child_atom_id。一般非对角矩阵的晶格与周期映射也须正确。
- [ ] P9.03 exact 模式原样复制掺杂/空位图样，报告人为周期相关性；randomize_after_repeat 用明确组成、补偿、种子和统计新建派生模型，不能称为逐原子相同。
- [ ] P9.04 分开 bulk、slab、晶界/异质界面构建；真空长度与实体厚度独立控制。记录取向、晶面、终止、面内变换/应变分配与边界。
- [ ] P9.05 确认 LAMMPS 二进制、版本、所需 package、CPU/GPU 路线和实际 potential 接口。程序能启动不代表 DeepMD/长程/分子拓扑包都已编译。
- [ ] P9.06 对现成势建立资格表：元素、bulk 相、缺陷、表面、界面、加载/温度、长程/电荷/自旋与聚合物拓扑。未覆盖项逐一标记，不把 bulk EAM/氧化物/有机势无标定拼接。
- [ ] P9.07 若需机器学习势，设计最小 ABACUS 标注集：平衡/应变/热扰动、目标缺陷、表面、实际界面 registry、张开/剪切与必要聚合物环境。只做平衡 AIMD 不覆盖断裂。
- [ ] P9.08 用一致 method_set 标注 E/F/应力，明确 dpdata/DeePMD 的原子类型、能量、力、应力/virial 单位与符号。先小数据转换/回读和独立构型对照，再训练。
- [ ] P9.09 按母轨迹、构型家族、加载路径/温度拆训练/验证/测试，不随机切相邻帧冒充独立测试。记录极端界面原子和断键环境误差，不只看平均力 RMSE。
- [ ] P9.10 在单卡 16 GiB 条件下建立训练资源基准，明确 batch/模型大小；不默认四卡显存池化。多模型委员会和主动学习仅在实际需要、版本相容时加入，不先搭通用 DP-GEN 平台。
- [ ] P9.11 资格验收除 E/F 外还比较晶格、应变/弹性、表面/相对 registry、分离曲线和目标温度稳定性。具体误差目标在运行前按物理量给定。
- [ ] P9.12 热传输要检查势与热流实现的多体/长程/维里支持；有 ε/P/电场任务还须额外自由度/标签，普通 E/F 势不自动给它们。
- [ ] P9.13 输出 structure.data、type_map、atom_map、parent_models、potential 文件/来源与 potential.json，写清合格范围/不支持项。新增元素、表面或聚合物后回到资格测试，不只改 type_map。
- [ ] P9.14 没有界面合格势时可验收扩胞算法、单相势和数据链，但不能把 P11 界面 MD 标为可执行。给出明确缺口与下一批标注预算。
- [ ] P9.15 以真实元素、真实目标组成/相和用户给定的范围建立资格样本，并为每类场景选正向基准（已知稳定结构、已通过的小胞或有来源的参考结果）。不以虚拟元素、任意替代元素或未标定混合势填补覆盖缺口。
- [ ] P9.16 建立能力覆盖矩阵：顺电/铁电、磁性、金属、电极/陶瓷界面、保留高分子和排胶后状态逐项记录已实现、需标注、未实现及适用边界。通用系统的通过条件是代表性场景有真实证据，不要求所有场景同时具备合格势。
- [ ] P9.17 将正常工况/设计对照的势资格与诊断/破坏加载资格分开验收；后者缺失时可继续正常性能预测，但不提交超出合格范围的破坏 MD，也不把未发生破坏解释成达标。
- [ ] P9.18 在界面势资格判定之前，消费 P4.17 已生成的、使用与 P11 相同真实元素/面内胞/约束的 ABACUS 界面 DFT 锚点（registry、间距、分离/剪切曲线及必要参考片段），并把锚点、来源任务和适用范围写入资格表。界面任务未选择或未计算时只记录执行事实；已选择但物理上不适用才记 `scientific_status=not_applicable`，无设计目标时 `design_assessment=not_assessed`。P11.03 只消费这些已生成的锚点，不反向定义 P9 的资格门，避免循环依赖。
- [ ] P9.19 按所选铁电、跨相变、局部极化或场驱动响应，明确极化/场模型路线：有效哈密顿量、局部软模/极化、诱导偶极、显式电荷/长程静电或场依赖势；把 P5 极化/介电/Born、必要 P7 力常数和 P4 DFT 标注的依赖写入模型。有效哈密顿量只有在选定实现和版本可执行时才可采用，不能把理论名称当作现成 LAMMPS 接口；只请求无场力学/热学时按对应资格执行。
- [ ] P9.20 核实实际 LAMMPS 接口、长程电荷/偶极实现、恒电势或外场边界、场能量和力的定义；对金属电极、绝缘陶瓷和高分子分别记录边界。普通 DeePMD/E/F/virial 势不自动包含极化、电场、去极化或电极屏蔽，未验证的接口只保留为未实现/待标注。
- [ ] P9.21 以独立结构/温度/应变/场和相态样本验证极化、Born/偶极、力、应力与能量一致性，并分开验收普通 E/F、极化、长程电边界和电-力耦合；极化验证失败时不能用普通 E/F 势替代，也不能把力场拟合误差当作介电误差。

完成门 G9 分为几何可用、势对具体场景合格；P10/P11 只使用已合格的场景子集。

### A.11 P10：LAMMPS 体相与局部微结构 MD

输入：G9 的相应合格势/结构与明确温度/边界。LAMMPS 本阶段输出原子/粒子行为，不输出整层 FEM。

- [ ] P10.01 从小胞开始对照 LAMMPS 与 ABACUS 的相同构型 E/F/应力，核实 units、type 顺序、边界、长程和力场参数。
- [ ] P10.02 做时间步对照与短 NVE 能量漂移，确认约束、质量与势实现稳定。恒温器不能用来掩盖积分/力场错误。
- [ ] P10.03 对真正 bulk 用合适 NPT 取得温度参考晶格/密度与热膨胀；说明各向异性、取向和采样。slab/真空不套三向 bulk 压强耦合。
- [ ] P10.04 按目标做弹性/应变响应、平衡与重复种子对照，说明静态弹性和有限速率响应的区别。
- [ ] P10.05 逐一增加明确晶界、局部孔隙、表面粗糙或缺陷，保持组分/取向/边界的可比对照，不把所有缺陷同时加入后声称找到单一机制。
- [ ] P10.06 规模由数千至数万原子的小基准逐步确定。记录 atom count、GPU/CPU、步耗时、显存/RAM、采样长度和输出体积，不承诺微米厚度逐原子计算。
- [ ] P10.07 局部应力明确 virial/体积/粗粒化窗口；界面/孔隙附近原子体积不唯一，给出对定义的敏感性。位置图着色不自动成为连续应力场。
- [ ] P10.08 按 `selected_purposes` 和 `selected_scenarios` 选择松弛、迁移/滑移或缺陷演化，保存事件定义和统计。迁移和制造组织中的孔隙可属于正常状态；只有额外诊断扰动和损伤加载按相应请求启用，不以事件名称自动判劣化。纳米时间/高应变率结果不能直接解释实验寿命。
- [ ] P10.09 如做 κl，选择与势匹配的 Green–Kubo/NEMD，检验热流、体积、采样和尺寸；不把温控输入能量自动叫热导，也不把 Ni 晶格项当总热导。
- [ ] P10.10 输出真实轨迹/统计、bulk reference、误差/有效范围、Slurm 任务记录及后续界面的温度/边界参考。按科学结果筛选代表性场景，不以动画是否流畅验收。
- [ ] P10.11 仅当 `selected_required_tasks` 或承诺的能力验证选择体相 MD/相应 observable 时，完成正常工况体相基线：结构/密度、弹性响应与卸载恢复、热传输和稳定性，在多个独立样本或种子上报告均值、离散度和误差。普通请求不因未选择全套 MD observable 而阻塞；当前 CaZrO3 验证案例使用400–580 °C（673.15–853.15 K）范围内五个计划点、外压1 atm，这些值不硬编码为通用系统默认。
- [ ] P10.12 将已选择的正常性能输出与条件诊断输出分开：若选定结构/弹性/热传输 observable，正常分支报告相应结构、弹性恢复、热传输、样本数和误差；诊断分支才按请求加入迁移、孔隙、缺陷演化或损伤事件。未观测到损伤只表示该轨迹未触发事件，不自动给出 `design_assessment=met`。
- [ ] P10.13 对每个代表性场景记录尺寸/时间/速率适用边界和 `scientific_status`；设计规格缺失时交付性能预测与误差，不虚构 conformance 阈值或把计算失败写成材料 `not_met`。
- [ ] P10.14 对已通过 P9.19–P9.21 的铁电/可极化模型，按正常有限温度工况采样极化态、局部有序参数、结构相和历史依赖；区分热涨落、相变、冻结和真正的极化翻转，不以单时刻净极化为零判定非铁电。
- [ ] P10.15 在给定工作点 E0 附近使用双侧小场扰动及幅度/采样对照，或适用的平衡涨落方法，计算 D、E 及 ∂D/∂E。总极化与电子/离子来源明确，局部极化是空间划分而非额外可重复相加的贡献；不把 P/E 当作所有偏压下的介电常数。
- [ ] P10.16 在选定机械边界下计算电致应变、极化—应变或压电响应的可逆加载/卸载，记录场幅、应变张量、速率、滞后和恢复；普通力学势只能交付无场弹性，不能补写电致响应。

### 两个执行案例的落地检查

1. CaZrO3：保持无掺杂、Pnma起始相与1 atm；采用最新烧制计算温区400–580 °C（673.15–853.15 K）；先完成结构、电子/完整 Cij、适用介电、声子/热学和普通势/正常 MD。缺陷集合、pO2/化学势、EF、带电修正和 NEB 只在明确选择后运行；不因非铁电而删除通用铁电能力。
2. BaTiO3：作为铁电能力案例，烧制温区800–1350 °C（1073.15–1623.15 K）已确定，先明确所选任务的高温相、机械/电边界和observable；低温铁电基准另立；DFT极化先验收引擎和参考，铁电MD另验极化/长程/场能量和力。模型资格后再产生P(T)、D(E)、微分介电和电致应变等生产结果，不将生产结果作为自己的循环前置条件。
3. 两案例都先交normal性能和误差；diagnosis/劣化是条件分支。没有产品目标时设计为not_assessed；已有目标但缺几何/物理证据才据具体目标给insufficient_evidence。不能用稳定/未损伤代替达标。

### 必须装入新详细执行计划的补项

- MFG-01：制造/烧后输入卡及缺失项检查（Ba/Ti、pO2、温度-时间、层厚、电极连续性、晶粒/孔隙/缺陷统计）。
- MODEL-01：分开真实晶粒核壳与 core-shell 势自由度，分别建立数据谱系和资格。
- RVE-IF-01、TRANSPORT-IF-01、DEVICE-IF-01、ACOUSTIC-IF-01：只定义所需参数、边界、验证和延期状态，不实现超出当前范围的求解器。
- RESULT-CARD-01、VALIDATION-01：统一结果卡、拟合/验证区分、误差/样本/外推范围和四层验收签出。
