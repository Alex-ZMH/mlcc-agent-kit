## 3. 通用多掺请求与构型合同

### 3.1 请求必须表达什么

请求沿现有Model/Study派生，增加一份显式组成计划，不新造任务调度器。建议字段如下；名称是待实现合同，不代表当前已有API。

| 字段组 | 最小内容 | 处理规则 |
| --- | --- | --- |
| 母体 | model/version、相、晶胞、允许变化的子晶格、原子ID/重复像谱系 | 保留母体来源；掺杂后不强行标为母体空间群 |
| 组成 | 每个子晶格各元素及空位的整数数量或占位分数；浓度分母 | A位比例、B位比例、全阳离子比例、全原子比例、配料mol%分别记录，不混用 |
| 超胞 | 显式整数变换矩阵、位点容量、规模上限 | 分数必须能落实为整数；不能静默四舍五入或自行扩成大胞 |
| 位点 | 显式site IDs，或有来源的候选site集合/子晶格映射 | 一个位置最终只有一个占位；替位和空位不能冲突；间隙位是另外的显式结构操作 |
| 补偿 | 自补偿、指定空位/间隙、电子补偿或未决；形式价态的来源 | 形式电荷账、净DFT电荷q、PP价电子数与实际电子占据分别记录 |
| 构型 | explicit / seeded_random / imported_SQS，数量、seed或外部工具配置 | 无默认构型遍历，不自动做全部距离/取向组合 |
| 对比 | 未掺reference、selected_properties、结构约束、温度/场/机械边界 | 不自动开完整温度、精度或材料矩阵 |

双掺/三掺按新增元素种类描述，不能把“同一稀土占A/B两个位置”称为双元素掺杂。高熵请求首先是多组分、可能多子晶格的占位问题；元素数本身不能证明熵稳定。可以按显式子晶格定义报告理想混合熵及其归一化，不能由此推出相稳定性、固溶上限或最终烧结组织。

Rost等的熵稳定氧化物工作结合相变实验和热力学讨论建立证据，不能简化为“放入五种元素即得到熵稳定材料”。本系统先支持可追踪的多组分构型，材料稳定性研究属于另选任务。[Rost等原文](https://www.nature.com/articles/ncomms9485)

### 3.2 最薄执行顺序

1. 解析组成分母与子晶格容量，生成精确整数占位账。不可表示时返回原始原因及所需容量关系，不代用户改配方。
2. 核对显式补偿账与DFT电荷；补偿未知时计划可保存，但不伪造中性模型。
3. 首先实现确定性位点清单；再接显式seed的随机占位。返回每个变化位置的parent atom ID、重复像、前后元素、最终atom ID和实际组成。
4. SQS优先接入外部已生成结构及其成分/相关函数报告；如选定ATAT等工具，再做一层明确参数的生成适配。记录子晶格、pair/triplet范围、目标相关函数、目标函数、实际停止状态及残差，不把单一随机结构改名SQS。
5. 构型集合以普通可读ID和显式seed记录，不引入哈希去重、自动寻找最低能构型或自动扩展计算数量。

ATAT的`mcsqs`输入可以按晶格位置表达多个组分及占位概率，输出结构与相关函数偏差；这支持使用现成实现，而非重新开发SQS搜索器。[ATAT mcsqs手册](https://axelvandewalle.github.io/www-avdw/atat/manual/node49.html)

## 4. 稀土/重元素对基底性质的计算链

### 4.1 先补方法表达，再选择材料近似

每个方法记录应保存：PP及NAO来源/版本/元素映射、价电子数、半芯态、4f在芯或价层的处理、相对论类型、显式自旋表示与初始磁矩、占据方式、SOC设置、U作用壳层/值/单位/来源及其投影定义。使用者选择不启用某项时同样保留原因，不为所有稀土或重元素自动开U/SOC。

本站按ABACUS 3.10.1实际版本审定。在线latest文档仅作为方法入口线索，不能直接替代该版本writer、原生输出及GPU路径检查。自旋/SOC需要匹配相应PP和实际表示；不能为适应现有nspin1接口而擅自选4f芯态近似，也不能把writer允许一个关键词当作reader已正确消费。[ABACUS自旋与SOC官方说明](https://abacus.deepmodeling.com/en/latest/advanced/scf/spin.html)

优先顺序为：方法元数据与输入真实支持 → 原生电子数/磁矩/占据消费 → 按所选性质接响应路径。磁性、SOC或金属占据状态不能自动送入已有固定非磁绝缘Born链。对应响应暂不支持时保留明确状态，电子/力学等独立功能继续开发。

这里不另建“4f资格”或“材料势资格”框架。4f/SOC/U仅落实为显式物理参数、出处和按需writer/parser/结果传递；未选择这些分支时，不阻塞普通多掺、性质差量或COMSOL出口。

### 4.2 对比对象与输出

比较请求必须指定母体reference和掺杂candidate集合。基准按同超胞规模/映射、相来源、几何约束和计算条件组织；已有5原子BTO结果不能直接充当40原子掺杂体系总能参考。允许固定同一晶胞的成分效应和各自弛豫后的总效应，但二者分别报告。

正常工况下的介电、力学、热和界面连接收益/代价与缺陷劣化诊断分别保留；不把多掺任务缩减为失效研究。设计指标未指定时交付差量及条件，不能擅自给“达标/不达标”或推荐最佳配方。

不同组成不要求完整方法字典逐字相等。应比较共同元素PP/NAO、泛函、基组体系、数值协议及物理边界；新增元素方法必须显式登记。k点按请求的实际网格/密度保存，不自动替换；U/自旋等物理处理有差异时标明对比混杂，不能默认为纯掺杂效应。

| 性质 | 首先复用什么 | 新的比较交付 | 不能据此直接给出的结论 |
| --- | --- | --- | --- |
| 结构 | 母体/派生模型与保存弛豫结构 | 晶格、体积、局域配位/键长变化和固定胞/弛豫分组 | 烧结后相含量、晶粒尺寸或固溶极限 |
| 电子 | 原生电子谱、占据、能隙及已支持的DOS产品 | band-gap差、费米/带边参考定义、选定电子态指标；缺PDOS时保持缺项 | 由能隙推出额定耐压、漏电寿命 |
| 缺陷 | 同方法能量参考及既有缺陷热力学 | 显式μ/EF条件下形成能/结合能差，指定缺陷关联 | 仅凭总能差宣布掺杂有利；不同计量裸总能不能当形成能 |
| 铁电/介电 | 已有Born、Γ、电子/离子响应与逐模产品 | 张量差、软模/耦合变化及未决原因；沿原子谱系关联 | 单点0 K结果证明温漂、损耗、铁电回线或X7R |
| 力学 | 已有弹性和原生应力/应变产品 | 同约定C张量差、参考应力与几何约束差 | 将未弛豫残余应力当器件热失配应力 |
| 热/输运 | 已有明确热响应及输运产品 | 同定义、同T/边界的差量；散射时间等模型参数单列 | 从Γ数据造有限q热容/热导，或从一段短MD造宏观热输运 |

比较产品保留原值、单位、差值、选定归一化、来源与原生状态；零基准不计算无定义相对变化。多个构型只按显式权重/分组汇总，不把同一轨迹块或重复导出的单点当独立构型。不默认比较就是“提高”，收益和代价由用户选定指标解释。

只要数值定义、单位和对象可对齐，工程差量可以输出，并原样携带未收敛/未资格等源状态；不因`production_qualification=false`一律抹掉差量。缺值或不可比时才保留对应null及具体原因。Ward等关于稀土掺杂BTO的研究显示，缺陷配对与空间分布会影响氧空位俘获和迁移，因而比较需要记录位点、配对与构型，而非只记录换了哪一种元素；这不授权本项目新增迁移势垒或metadynamics任务。[Ward等原文](https://doi.org/10.1002/adfm.201905077)

## 5. LAMMPS输入端的多元素扩展

保持Model→potential/model card→现有LAMMPS task→site runner→Slurm的架构。新增组成计划需要传递最终元素集合、元素顺序/type映射、原子ID、质量、atom style、电荷/键拓扑（仅所选模型需要时）、边界、Prism转换及其逆映射、物理单位和参考模型。

MACE与ABACUS→DeePMD→LAMMPS是独立可选路线。每条路线分别记录模型实际元素支持、类型顺序和有效任务范围，不互相充当正确性证明，不在本次规划中增加训练。模型可接受某原子序数只说明接口覆盖，不表示该掺杂局域环境已有可靠训练标签；这一材料适用性缺口不阻塞组成/数据传递的软件验收。

普通E/F模型不产生电场耦合。若后续用户选电—热—力耦合MD，需另有明确电荷、长程、极化及外场模型；当前可以分别交付DFT介电与MD机械/热参数，不能把二者并列保存称为已耦合。

## 6. LAMMPS输出到连续模型的最小参数表

先做求解器无关的SI参数包，并对**已选定的COMSOL**提供薄适配。包内允许有来源的缺项及未决项，不能用零、典型值或其他材料自动补齐。它不是原子应力到FE网格的自动映射，也不是完整器件模型。

| 物理量 | SI/约定 | 影响后续模拟的条件 | 当前缺口的处理 |
| --- | --- | --- | --- |
| 密度ρ | kg/m³ | 晶相、组成、温度、孔隙；原子胞密度不同于器件体密度 | 分清来源，孔隙/致密化由显式输入提供 |
| 弹性C | Pa，完整张量或声明Voigt顺序 | 材料坐标、剪切因子、应力/应变度量、小应变范围、T和预应力 | 先交已有有效张量，未支持的温度表不插值生成 |
| 热膨胀α与参考温度 | K⁻¹、K | 线/体膨胀、方向、无应力参考态、工艺与载荷历史 | 局部热应力差不能自动替代α(T) |
| 热容Cp与导热k | J/(kg·K)、W/(m·K) | Cp/Cv差别、量子/经典定义、方向、T、Ni电子与晶格通道 | 缺源明确null；不得用短轨迹温度波动直接填材料卡 |
| 热接触G/R | W/(m²·K)、m²·K/W | 界面面积/数量、热流分配、温差、稳态区间、双周期几何 | 尚未得到有效G/R时只保留原始热响应，不导出伪值 |
| 界面牵引/刚度 | Pa、Pa/m；位移m | 法/切向方向、夹持、原始反力、单界面归属、参考开口、混合模 | 胞净反力和区间刚度只能按其原义导出，不能自动成为单界面CZM |
| 分离能/断裂参数 | J/m²，定义随模型声明 | 可逆功、有限速率耗散、塑性/黏弹、峰值强度及混合模规律 | 三点小位移/卸载不确定完整损伤软化律；不重复计耗散 |
| 介电ε | 相对量无量纲，绝对量F/m二选一显式标明 | 固定应变/固定应力、高频/静态、取向、T/E/f、稳定分支 | 电子与离子项分别交付，BTO静态null保持 |
| 电导与热电 | S/m、V/K等按物理量单列 | DC/AC、温度、载流子、松弛时间、单位/能量参考 | σ与σ/τ不能混；普通E/F MD不能提供这些参数 |
| 压电/电致伸缩 | e为C/m²，d为C/N；其他形式显式声明 | C与ε的固定电/机械边界、极化分支和坐标体系 | 缺完整耦合张量时不从Born电荷或单个响应值替代 |
| 塑性/黏弹/损伤 | 按所选本构 | 速率、时间尺度、屈服/硬化、损伤历史、非线性温度依赖 | 属条件开发；本轮不由少数MD点拟合完整本构 |

LAMMPS `stress/atom`是带约定符号的压力×体积量，并可能含动能项；转成连续应力必须显式给区域/体积、平均方式和坐标映射。[LAMMPS官方说明](https://docs.lammps.org/compute_stress_atom.html) 逐原子virial图不能直接当有限元应力场。

参数包还须携带：model/Study/组成/构型、source task/job/终态、原生文件、单位转换、材料坐标和目标坐标、适用T/E/f/应变/速率/尺寸、参考态、统计窗/误差定义、原始状态与缺项理由。晶粒取向、孔隙、层厚、界面几何、电极/端头、约束和电热载荷由器件模型另行提供，不能从原胞推断。

### 6.1 COMSOL出口具体交付

出口建议名为`export_comsol_material_package`。交付包括`parameters-si.json`、带单位和方向的参数表、选定物理接口的字段映射、COMSOL材料XML或Java API材料创建模板、温度函数数据文件与导入说明，以及缺项清单。先实现其中一种材料创建格式，不同时重造多套适配；API模板通过官方`material().propertyGroup()`设置材料属性。材料XML也有官方导入机制。[COMSOL材料API与XML](https://doc.comsol.com/6.3/doc/com.comsol.help.comsol/comsol_api_general.47.40.html)

| MLCC量 | COMSOL目标/命名 | 最薄适配要求 |
| --- | --- | --- |
| ρ、Cp、k | `density`、`heatcapacity`、`thermalconductivity` | SI；k保留标量/3×3形式及材料坐标，不把κ/τ直接写入k |
| εr、σ、Seebeck | `relpermittivity`、`electricconductivity`、`seebeckcoefficient` | 相对ε与绝对ε分开；σ/τ缺τ不填σ；静态/高频项和温度范围明确 |
| C | Linear Elastic Material的各向异性Elasticity matrix D | 声明目标Voigt顺序`xx,yy,zz,yz,xz,xy`，应变向量剪切项为工程剪切；同时重排矩阵两轴，不只重排列 |
| α与Tref | Thermal Expansion输入类型、材料方向与参考温度 | 声明切线α、割线α或热应变；不得把三种形式互换成同一数组 |
| G/R | Thermal Contact中的接触导热/热阻表达式 | 输入显式界面selection/pair、面积/界面数量、温度定义；只有G/R已有对应定义才填数 |
| 界面法/切向曲线 | 选定机械接触/弹簧/黏聚节点的参数或函数表 | 首版交表和映射模板；缺单界面归属、损伤/混合模数据时不生成完整CZM材料 |

基本属性名和单位接口据COMSOL官方API；具体物理节点的tag、材料组名称和功能开关须按**目标安装版本**生成并记录，不能猜一个看似合法的键就宣称已导入。6.3是本次文档参照，不是本站已安装版本证据。

张量映射先恢复明确的二/四阶张量，完成源Cartesian到材料/目标坐标的旋转，再按目标顺序收缩；保存旋转矩阵、剪切定义和源/目标顺序。COMSOL线弹性可选择Standard或Voigt材料顺序，不能依赖默认值。[COMSOL线弹性](https://doc.comsol.com/6.3/doc/com.comsol.help.sme/sme_ug_solid.07.007.html) LAMMPS六分量顺序为`xx,yy,zz,xy,xz,yz`，不应原样塞入COMSOL六维矩阵。

温度依赖输出单独的数据表与函数名、参数单位K、值单位、插值方式和显式外推政策。单一温度点只交单点；没有温度序列就不造α(T)、C(T)或k(T)。默认规划为不擅自外推，真正导出请求须明确其区间外行为。COMSOL支持文件插值及参数/函数单位；导出与原生导入仍是两步。[COMSOL文件插值](https://doc.comsol.com/6.3/doc/com.comsol.help.comsol/comsol_ref_definitions.21.063.html) 热膨胀必须同时交无热应变参考温度，以及切线/割线/热应变形式和取向。[COMSOL热膨胀](https://doc.comsol.com/6.3/doc/com.comsol.help.sme/sme_ug_solid.07.033.html)

首版真实COMSOL读入尚待环境：先验证文件/模板生成及MLCC规则消费者（数值仍在v100），后续在有相应版本和模块的COMSOL中读取材料与函数，保存原生导入信息、单位、张量和取向读回值。**模板生成通过只记export-template-passed；真实读入才记COMSOL-import-passed**。两者均不自动等于网格、边界或器件求解通过，本轮不执行这些动作。

## 8. 什么情况下可以称为完成

- **多掺建模完成**：请求→整数占位/补偿→模型/谱系→实际组成→下游输入映射连通，正例和不可表示条件均有v100证据。不能仅凭多次substitute调用宣称全流程完成。
- **掺杂影响比较完成**：实际同家族基准/掺杂源在声明边界下进入比较产品，单位、计量、来源、未决和差量均正确；结论允许“不改善”或“未决”。是否满足应用指标另行判断。
- **连续参数出口完成**：真实保存产品进入明确定义参数包并由消费者读回；缺项可交付但不能称已形成完整FE模型。
- **某求解器接入完成**：选定版本真实导入所支持材料参数，原生读入/错误证据保存；求解、几何网格与耦合验证另按所选范围验收。

只对修改或缺失的路径补检查；算法例子、真实材料实例和安装接入记录分别保留，复用同一份真实证据。某个材料没有所需物性或出现软模，不阻塞其它已就绪功能开发。
