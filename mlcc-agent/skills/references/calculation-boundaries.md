# 当前计算能力边界与冲突解释

本页用于设计方案、澄清输入和解释执行反馈。它随 Bundle 与模块代码一起发布，表示所绑定版本的当前实现，后续版本可继续开放；不要把历史限制当永久物理定律。先用公网目录和对应领域方法 Skill 确认操作、输入 schema 与实际版本，不能把“能调用工具”解释为“支持任何模型”。阅读说明不等于全部后端校验已经通过。

## 方案与反馈的处理方式

1. 先辨别用户要的物理量、维度、几何、材料模型、边界条件和已有证据，再选择领域操作。缺科学输入时只澄清所缺项，不补合成默认值。若请求超出当前能力，指出具体不支持的部分，再说明可提供的较简方案及其能力损失；获得用户接受后才改变科学假设。
2. 网格数量超过推荐是资源提示，不是拒绝计算的理由。FEM、RVE、相场均不得仅因单元数或相场自由度超过旧值阻断，不自动粗化、删晶界、减晶粒、减少器件层数或把三维改二维。推荐不保证时间、内存或精度，真实资源不足和数值失败仍需如实反馈。
3. 遇到冲突时先读取该任务保存的 errors、日志与检查：说明“哪个操作、哪组输入、命中了什么当前实现限制”，区分未实现能力、输入/几何错误、分辨率不足、数值失败、环境/资源问题与证据缺失。错误中包含旧预算值时，先核对任务绑定版本，不将新版本的放宽追溯到旧任务。
4. 只读目录可能未穷举内核的关系规则；具体科学语义以同一版本的模块方法说明、schema、代码校验和任务原始反馈为准。说明与实际反馈不一致时明确指出该差异，不猜测成功、不绕过有效性或稳定性检查。
5. 计算已经提交后，不为修复一次解释、适配新版或回答追问而更改其输入、payload 或版本，不自动取消、重提或替换已保存结果。超时/连接中断不证明求解器已停止，先核对原任务状态。重复错误不以同参数不断新建任务来试。

## FEM：器件模型范围

- 当前八个操作是参数化二维 MLCC；有效间隙数为 1..79。这是器件几何接口范围，不是网格数量上限。
- 静电是均匀线性各向同性无损介质、理想电极模型；电热是规定电损耗到稳态热的单向耦合，不含温度反向反馈或瞬态热机耦合。
- AC-EQS 与电磁操作各自使用明确的材料、端口、频率和热边界。电磁是受控的闭合引导 Ex/Ey/Hz 模型、mu_r=1，不等于通用三维封装、板级辐射或磁滞模型。
- FEM 0.4.3 起原 50000/150000 单元值只作宿主软推荐，部署字段仍名为 max_cells；规划与实测超出只提示。
- 端口量不自动等于商用 ESR/ESL/SRF；材料/安装条件、网格收敛与实物对照按任务实际检查状态报告。

详见[静电方法](../../modules/fem/skills/linear-electrostatics/SKILL.md)与[器件耦合方法](../../modules/fem/skills/mlcc-device-coupling/SKILL.md)。

## RVE：组织、维度与分辨率

- 二维源构造器要求正方形单胞。二维多晶晶粒数支持 4/9/16/25/36；三维支持 8/12/16/20/27，不接受任意晶粒数。
- 二维多晶晶界宽度支持 0..0.08，零宽度不建 3000 晶界相；材料必须精确覆盖实际芯、壳、孔和晶界区域，不添加假材料。三维多晶的非零晶界及壳层尚未开放。
- 多晶孔隙是当前受控中心圆孔/球孔构造，孔隙分数范围 0..0.08，不等于任意随机孔洞分布。不要用它替代用户要求的真实孔形或统计组织。
- 正晶界/壳层仍有解析要求：二维目标 h≤最薄层宽度/1.5，三维相应检查为 /1.2。物理尺寸需先通过统一单位映射理解，normalized_* 是无量纲，不能直接填 nm。
- RVE 0.1.4 起单元数仅为推荐；0.1.5 起取消二维 h≥0.003、三维 h≥0.025 的人为细化下界，要求有限正 h，并保留原粗网格上界。不能再用这些旧下界解释新版本的薄晶界请求。
- 当前输出为静态线性材料的有效张量；数值通过不代表统计代表性、材料标定或任意局部场精度已经验证。

详见[RVE 方法](../../modules/rve/skills/static-rve/SKILL.md)。

## 相场：模型、时间与静态分支

- 标量模型仅一个 y 向极化分量；空间三维不等于三分量极化。全矢量与标量不能混用能量系数、畴壁宽度及边界语义。
- 全矢量和静态切线目前是 synthetic_tetragonal_quartic_v1、all_surface_voltage，a<0、b>0、c>2b，g/epsilon>0；矢量演化还需正 mobility。不支持任意标定材料、一般电弹耦合或任意边界条件。
- 相场 0.4.1 起取消总单元数、每轴划分数、矢量 25000 总自由度和切线 3300 总自由度硬上限；max_cells、max_work、max_history_bytes 只作正整数软推荐，不让工作量/输出估计间接挡住细化。
- 切线仍执行完整稠密稳定性分析；预检给出的单矩阵内存估计还不含其他矩阵与工作区，不能因规模大跳过稳定性检查后输出“有效材料张量”。
- 时间积分控制仍有效：矢量 reduced dt≤0.2，max_steps 为 1..2000、max_halvings 为 0..6；波形仅明确支持的恒场/三角波/阶梯。静态切线使用偏置路径，不是时间波形，路径长度 1..100，equilibrium_atol≤1e-8。畴壁/随机谱必须被空间网格解析。
- 不稳定或近奇异分支可以返回拒绝或不完整能力，不能把 Newton 收敛当稳定性证明，也不能把有限时间 P–E 斜率当静态切线张量。

详见[标量](../../modules/phase_field/skills/mlcc-scalar-ferroelectric/SKILL.md)、[全矢量](../../modules/phase_field/skills/mlcc-vector-ferroelectric/SKILL.md)和[切线](../../modules/phase_field/skills/mlcc-tangent-dielectric/SKILL.md)方法。

## SPICE：受控电路与采样

- 当前是显式给定 C/ESR/ESL/漏电参数的线性集中 RLC 与受控拓扑，不是任意网表，也不会从器件外形猜电路参数。
- 当前实现/部署仍有分支数 8、AC 采样 21000、瞬态采样 100000 的限制；这些不是本轮网格放宽的对象，实际值以宿主绑定与模块反馈为准。
- DEC 扫频端点需与显式 points_per_decade 网格对齐。瞬态有固定后沿 100 ns 诊断，可能要求比用户短脉冲更长的记录窗口；遇到该冲突要解释是当前诊断约束，不能说物理上不允许短脉冲，也不能静默延长用户波形。
- 部分来源字段当前仅接受 synthetic/manual。这是接口枚举，不表示只有这两种科学来源存在；不能捏造来源来绕过校验。

详见[电路 Skill](../run-mlcc-spice/SKILL.md)及其方法链接。

## DFT / MD：方法与资格边界

- DFT 默认生产引擎是 ABACUS；只有用户明确指定 VASP 才选择 VASP，不自动回退。当前 ABACUS 适配器支持受限的 PW/LCAO 与 SCF/固定晶胞松弛组合；LCAO 要求中性、nspin=1、fixed occupation SCF；带电任务仅固定晶胞 SCF，不接受应变变换。
- PP/NAO 的元素、资源 ID 和方法适用性通过运行时资源目录查询，不在本页抄一份可用元素表。目录中存在资源、引擎能启动与材料/方法科学资格是不同事实。
- MD 普通入口仍有 engineering fixture 限定；真实模型只在已声明的 purpose 路线开放，如 potential_qualification、interface_*、md_native_sampling、md_bulk_thermal / bulk_thermal_transport。势、pair_style、协议与硬件绑定必须匹配，不将示例 fixture 当生产模型，也不自动换势。
- 这些是当前接入范围；后续版本开放新方法或用途时同步更新同版 Skill，不能继续引用旧限制阻止已支持的操作。

详见[DFT Skill](../run-mlcc-dft/SKILL.md)与[MD Skill](../run-mlcc-md/SKILL.md)。

## 版本与证据维护

本轮发布目标为 Bundle 0.60.5：FEM 0.4.3、phase_field 0.4.1、RVE 0.1.5，SPICE 与 DFT/MD 科学能力沿用原版。后续每次开放能力都在同次发布中更新本页与领域方法 Skill，保留旧 Bundle 给旧对话/任务使用。当前结论按实际 execution、数值检查、科学检查及原生产物分别报告，not_checked 不因文字说明或版本升级变成 passed。
